## Ordering and provenance

The operator explicitly requested renumbering every problem by difficulty. The [complete map](problem-numbers-2026-10-20.csv) records all 89 old/new numbers. Existing difficulty labels are coarse instructional tiers, not measured solve-rate ratings; order within each existing tier is retained. Slug URLs and stored submission references remain unchanged. Old numeric aliases now refer to the new catalog numbers.

Reviewed the 69 existing statements and nearest overlapping objectives before authoring. Standard algorithm topic references were the official [CSES catalog](https://cses.fi/problemset/) and [AtCoder ABC403 task listing](https://atcoder.jp/contests/abc403/tasks/). No external statements, test data or solutions were copied. This review does not claim that the algorithms are globally novel.

Problem packages, hidden data, validators and references remain private, with encrypted off-host recovery copies. They are deliberately absent from this public Git repository. For a new AI session, use the protected operator source and the canonical [authoring workflow](../making-problems.md); a public checkout alone cannot reproduce private-package validation.

See the [release record](../releases/PROBLEM_EXPANSION_2026-10-20.md) for actual checks, infrastructure state, limitations and recovery.
