# ไม่ได้ลืมแค่ไม่ได้เจอ (Flashback)

มีบันทึก N วัน (`a[1..N]`) แบ่งเป็นช่วงละ K วันติดกัน
- ช่วงที่ลืมได้แล้ว: ผลรวมน้อยสุด + วันเริ่มต้น (เสมอกันเอาช่วงแรก)
- ช่วง Flashback: ผลรวมมากสุด + วันเริ่มต้น (เสมอกันเอาช่วงแรก)

## Input
- บรรทัดแรก: `N K` (1 <= K <= N <= 100000)
- บรรทัดที่สอง: `a[1..N]` (0 <= a[i] <= 1000)

## Output
- บรรทัดแรก: `ผลรวมน้อยสุด วันเริ่ม`
- บรรทัดที่สอง: `ผลรวมมากสุด วันเริ่ม` (วันนับจาก 1)

## ตัวอย่าง
```
input:
10 3
5 4 2 0 1 0 1 6 8 7

output:
1 4
21 8
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 256 MB
