# สี่เหลี่ยมใหญ่สุดในฮิสโตแกรม (Largest Rectangle)

ฮิสโตแกรม n แท่ง (กว้างแท่งละ 1, สูง `h[i]`) หาพื้นที่สี่เหลี่ยมที่ใหญ่สุดที่ใส่ได้
มีหลายชุดข้อมูลในไฟล์เดียว — เจอ `n = 0` ให้หยุด (ไม่ประมวลผลชุดนั้น)

## Input
- หลายชุด: บรรทัดแรกของชุดคือ `n` (0 <= n <= 500), ถัดไปคือความสูง n ค่า (0 <= h[i] <= 10^5, อาจขึ้นบรรทัดใหม่ได้)
- `n = 0` = จบไฟล์

## Output
- ชุดละ 1 บรรทัด: พื้นที่มากสุด

## ตัวอย่าง
```
input:
7
2 1 4 5 1 3 3
4
1000 1000 1000 1000
0

output:
8
4000
```

## Subtasks
- 50 คะแนน: มีชุดข้อมูลเดียว
- 50 คะแนน: เต็ม

## Limits
