# ผลรวมเลขโดด (Digit Sum)

พักเที่ยงในค่าย พราวชวนเพื่อนเล่นเกม "บวกเลขโดด" กติกาคือสุ่มจำนวนมาหนึ่งตัว
ใครบวกเลขทุกหลักเข้าด้วยกันได้เร็วสุดชนะไปเลย พราวแพ้มาสามรอบติด
เลยขอซ้อมมือก่อนแข่งจริงด้วยโปรแกรมที่ตรวจคำตอบให้
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion ห้ามลูป — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- จำนวนเต็ม `x` ตัวเดียว (0 <= x <= 10^18)

## Output
- บรรทัดเดียว: ผลรวมเลขโดด

## ตัวอย่าง
```
input:
1234567

output:
28
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
