# จุดไฟประดับใกล้เวทีที่สุด (Stage Lights)

ติงลี่ได้รับมอบหมายให้ติดหลอดไฟประดับรอบเวที โดยกำหนดจุดติดตั้งเป็นพิกัดบนแผนที่
มีจุดทั้งหมด `N` จุด เวทีหลักอยู่ที่จุดกำเนิด (0, 0) ตามแผนผังที่นิวเป็นคนวาดไว้

เจต้องการเดินสายไฟตามลำดับจาก "จุดที่อยู่ใกล้เวทีที่สุด" ไปไกลที่สุด
โดยระยะทางวัดแบบระยะห่างยกกำลังสอง คือ `x^2 + y^2`
ถ้าจุดสองจุดอยู่ห่างเท่ากัน ให้จุดที่ค่า `x` น้อยกว่าไปก่อน
และถ้า `x` เท่ากันอีก ให้จุดที่ค่า `y` น้อยกว่าไปก่อน

จงพิมพ์พิกัดทุกจุดตามลำดับที่ต้องเดินสาย

## Input
- บรรทัดแรก: `N` (1 <= N <= 100000)
- อีก `N` บรรทัด: `x` และ `y` (|x|, |y| <= 10000)

## Output
- `N` บรรทัด แต่ละบรรทัดคือ `x` และ `y` ตามลำดับ

## ตัวอย่าง
```
input:
4
3 4
1 1
-2 0
0 5

output:
1 1
-2 0
0 5
3 4
```
ระยะยกกำลังสอง: (1,1) = 2, (-2,0) = 4, (3,4) = 25, (0,5) = 25
สองจุดหลังเท่ากัน จึงดู `x`: 0 น้อยกว่า 3 จุด (0,5) ไปก่อน

## Subtask
- กลุ่ม 1 (40 คะแนน): N <= 100
- กลุ่ม 2 (60 คะแนน): ไม่มีเงื่อนไขเพิ่มเติม

## Limits
- เวลา 1 วินาที, หน่วยความจำ 256 MB
