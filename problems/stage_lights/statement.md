# จุดไฟประดับใกล้เวทีที่สุด (Stage Lights)

จุดติดตั้ง `N` จุด เวทีอยู่ที่ (0, 0)
เรียงจุดจากใกล้ไปไกล วัดด้วยระยะยกกำลังสอง `x^2 + y^2`
ถ้าเท่ากันให้ `x` น้อยกว่าก่อน ถ้า `x` เท่ากันอีกให้ `y` น้อยกว่าก่อน

## Input
- บรรทัดแรก: `N` (1 <= N <= 100000)
- อีก N บรรทัด: `x y` (|x|, |y| <= 10000)

## Output
- N บรรทัด: พิกัดตามลำดับที่ต้องเดินสาย

## ตัวอย่าง
```
input:
4
3 4
1 1
-2 0
0 5

output:
1 1
-2 0
0 5
3 4
```
(ระยะ: 2, 4, 25, 25 — สองจุดหลังเท่ากัน ดู x: 0 มาก่อน 3)

## Subtask
- กลุ่ม 1 (40 คะแนน): N <= 100
- กลุ่ม 2 (60 คะแนน): ไม่มีเงื่อนไขเพิ่มเติม

## Limits
- เวลา 1 วินาที, หน่วยความจำ 256 MB
