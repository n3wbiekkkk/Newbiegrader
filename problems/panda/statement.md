# แพนด้าหาสบู่โอ (Panda50O)

พี่นะดีมสั่งน้องปลูกต้นไผ่ (`P x` = ปลูกต้นที่ความอร่อย `x`),
รดน้ำหวาน (`A v` = ความอร่อยของทุกต้นที่ปลูกอยู่ +`v`),
และถอน (`S` = ถอนต้นที่อร่อยน้อยสุดให้แพนด้า)

## Input
- บรรทัดแรก: `Q` (จำนวนคำสั่ง, 1 <= Q <= 100000)
- อีก Q บรรทัด: คำสั่งละบรรทัด
  - `P x` (1 <= x <= 10^9)
  - `A v` (1 <= v <= 10^9)
  - `S`

## Output
- ทุกครั้งที่เจอคำสั่ง `S`: พิมพ์ความอร่อยของต้นที่ถอน (หลังรวมน้ำหวานที่รดไปทั้งหมด)
- ถ้าไม่มีต้นไผ่เหลืออยู่: พิมพ์ `OH NO ICY PLS HELPPP`

## ตัวอย่าง
```
input:
8
P 8
P 5
A 4
S
P 6
S
S
S

output:
9
6
12
OH NO ICY PLS HELPPP
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 512 MB
- ระวัง: ค่าความอร่อยรวมอาจเกิน 32-bit (แนะนำ 64-bit)
