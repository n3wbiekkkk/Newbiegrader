# จำลอง DNA (DNA Replication)

รับสาย DNA แล้วสร้างสายคู่สมย้อนกลับ (Reverse Complement):
1. Complement: A ↔ T, C ↔ G
2. Reverse: พลิกกลับหน้าหลัง

**ข้อนี้ใช้ภาษา/วิธีใดก็ได้** (ต้นฉบับ PDF สั่งเติมฟังก์ชันด้วย pointer — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดเดียว: สาย DNA ตัวพิมพ์ใหญ่ A/T/C/G (ยาวไม่เกิน 1000)

## Output
- บรรทัดเดียว: สายคู่สมย้อนกลับ

## ตัวอย่าง
```
input:
ATGC

output:
GCAT
```
(TACG พลิกเป็น GCAT)
