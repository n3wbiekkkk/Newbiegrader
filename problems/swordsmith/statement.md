# ช่างตีดาบแห่งวังหลวง (Swordsmith)

ข้าวปั้นเป็นช่างตีดาบ มีแท่งโลหะ `N` แท่ง ต้องหลอมรวมจนเหลือแท่งเดียว
แต่ละครั้งเลือก 2 แท่งเบาสุดมาหลอม (พลังงาน = น้ำหนักรวม) แท่งใหม่กลับเข้ากอง
จงหาพลังงานรวมทั้งหมด
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่งเขียนฟังก์ชัน — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดแรก: `N` (2 <= N <= 100)
- บรรทัดที่สอง: น้ำหนัก `N` ค่า (1 <= ค่า <= 1000)

## Output
- บรรทัดเดียว: พลังงานรวม

## ตัวอย่าง
```
input:
6
1 1 1 1 1 1

output:
16
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
