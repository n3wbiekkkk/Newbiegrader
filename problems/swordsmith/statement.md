# ช่างตีดาบแห่งวังหลวง (Swordsmith)

ในงานวัดมีโรงตีดาบสาธิต ข้าวปั้นรับบทช่างตีดาบประจำโรง
เขามีแท่งโลหะ `N` แท่งน้ำหนักต่างกัน ต้องหลอมรวมจนเหลือแท่งเดียวเพื่อตีเป็นดาบยักษ์โชว์
เตาหลอมกินพลังงานตามน้ำหนักรวมของ 2 แท่งที่หลอมแต่ละครั้ง
ข้าวปั้นอยากเสียพลังงานรวมน้อยที่สุด (หลอมคู่เบาสุดก่อนเสมอ) แท่งใหม่ที่ได้กลับเข้ากองต่อ
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่งเขียนฟังก์ชัน — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดแรก: `N` (2 <= N <= 100)
- บรรทัดที่สอง: น้ำหนัก `N` ค่า (1 <= ค่า <= 1000)

## Output
- บรรทัดเดียว: พลังงานรวม

## ตัวอย่าง
```
input:
6
1 1 1 1 1 1

output:
16
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
