# วาร์ปอวกาศ (Warpz)

มีสถานีวาร์ปหมายเลข 1..N ยานจอดอยู่ที่สถานี 1
จากสถานี `i` วาร์ปไปสถานี `i+1 .. i+a[i]` ได้ (a[i] คือกำลังวาร์ปสูงสุด)
ถามว่าไปถึงตำแหน่งที่มากกว่า N ได้หรือไม่ ตอบ `YES` / `NO`

## Input
- บรรทัดแรก: `N` (1 <= N <= 1000)
- บรรทัดที่สอง: `a[1]..a[N]` (0 <= a[i] <= 9)

## Output
- `YES` ถ้าถึงตำแหน่ง > N ได้ ไม่งั้น `NO`

## ตัวอย่าง
```
input:
8
3 0 7 1 0 0 0 0

output:
YES
```

## Subtasks
- 20 คะแนน: N <= 10
- 30 คะแนน: N <= 100
- 50 คะแนน: เต็ม (N <= 1000)

## กับดัก
- a[i] ใหญ่แต่อยู่สถานีที่ไปไม่ถึง (เช่น `[2,2,0,0,9]` ตอบ NO)
- N = 1, a = [0] ตอบ NO (อยู่ที่ 1 ไปไหนไม่ได้)
- greedy O(N) ก็พอ ไม่ต้อง exponential
