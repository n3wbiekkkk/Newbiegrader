# ผลรวมตัวเลขที่ซ่อนในข้อความ (Hidden Digits)

นิวล็อกตู้เก็บของชมรมแล้วดันลืมรหัส เหลือแค่กระดาษโน้ตแผ่นเดียวที่จดข้อความประหลาดไว้
เขาจำแม่นอย่างเดียวว่ารหัสคือ "ผลรวมของตัวเลขทุกหลักที่ซ่อนอยู่ในข้อความนั้น"
(ตัวเลขติดกันก็นับทีละหลัก ไม่ได้นับเป็นจำนวนเต็ม) ช่วยนิวหารหัสก่อนครูมาเห็น
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่งเขียนฟังก์ชัน — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- ข้อความ 1 คำ ยาว 1–100 ตัวอักษร (A–Z, a–z, 0–9 ไม่มีช่องว่าง)

## Output
- บรรทัดเดียว: ผลรวมของตัวเลขทุกหลัก

## ตัวอย่าง
```
input:
X4Y5Z6

output:
15
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
