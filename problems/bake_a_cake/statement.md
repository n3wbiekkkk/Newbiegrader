# อบเค้ก (Bake a Cake)

มีสูตรเค้ก (ปริมาณต่อ 1 ก้อน + ชื่อวัตถุดิบ, n บรรทัด) คั่นด้วยบรรทัด `-1`
แล้วมีวัตถุดิบที่มีอยู่ (n บรรทัด, ลำดับอาจไม่ตรงสูตร)
เค้กที่ได้จากวัตถุดิบแต่ละชนิด = ปัดเศษลงของ `มีอยู่ / ใช้ต่อก้อน`
คำตอบ = ค่าน้อยสุด (ตัวจำกัด) ถ้าเสมอกันให้เอาตัวที่มาก่อนในสูตร

## Input
- n บรรทัดแรก: `<จำนวนจริง> <ชื่อ>` (0 <= จำนวน <= 10000, ชื่อไม่มีช่องว่าง)
- บรรทัด `-1`
- อีก n บรรทัด: `<จำนวนจริง> <ชื่อ>` ของที่มีอยู่ (n <= 100)

## Output
- บรรทัดแรก: `X cake(s)`
- บรรทัดที่สอง: `You should buy more NAME` (ชื่อตัวจำกัดตัวแรกตามลำดับสูตร)

## ตัวอย่าง
```
input:
1 cup-white-sugar
0.5 cup-unsalted-butter
2 eggs
-1
3 cup-unsalted-butter
2.5 cup-white-sugar
5 eggs

output:
2 cake(s)
You should buy more cup-white-sugar
```

## Subtasks
- 20 คะแนน: วัตถุดิบ 1 ชนิด
- 20 คะแนน: วัตถุดิบ 2 ชนิด
- 60 คะแนน: เต็ม

## Limits
- เวลา 0.5 วินาที, หน่วยความจำ 32 MB
