# ที่จอดรถ (Parking Slots)

ณ ไซต์ก่อสร้างแห่งหนึ่ง มีช่องจอดรถทั้งหมด `N` ช่อง เรียงกันเป็นแถวยาวจากหมายเลข 1 ถึง `N` โดยแต่ละช่องจอดถูกออกแบบมาให้จอดรถได้เฉพาะชนิดที่กำหนดเท่านั้น รถที่มาใช้งานมีทั้งหมด `M` ชนิด (แทนด้วยหมายเลข 1 ถึง `M`) โดยช่องจอดที่ `i` ถูกกำหนดให้จอดได้เฉพาะรถชนิด `a[i]` เท่านั้น

จงเขียนโปรแกรมช่วยจัดการที่จอดรถ ซึ่งมีคำสั่งการทำงาน `Q` คำสั่ง ดังนี้

- คำสั่งหาที่จอดรถ (`0 p`): มีรถชนิด `p` เข้ามา ต้องการหาช่องจอดรถที่ว่างอยู่และถูกออกแบบมาสำหรับรถชนิด `p` ที่มีหมายเลขช่องจอดน้อยที่สุด (ใกล้ทางเข้าที่สุด) หากพบช่องจอด ให้แสดงหมายเลขช่องจอดนั้น แล้วทำการจอดรถลงในช่องนั้นทันที (รับประกันว่าจะเหลือที่จอดรถสำหรับรถทุกคันที่เข้ามา)
- คำสั่งรถออก (`1 r`): รถที่จอดอยู่ในช่องจอดหมายเลข `r` นำรถออก ทำให้ช่องจอดหมายเลข `r` กลับมาเป็นช่องว่างอีกครั้ง (คำสั่งนี้ไม่มีผลลัพธ์ต้องแสดง)

## Input

- บรรทัดแรก: จำนวนเต็ม `N M Q` (2 <= N <= 1000000, 1 <= M <= 100000, 1 <= Q <= 200000)
- บรรทัดที่สอง: จำนวนเต็ม `N` จำนวน `a[1..N]` (1 <= a[i] <= M)
- อีก `Q` บรรทัด: คำสั่งละหนึ่งบรรทัด (`0 p` หรือ `1 r`)

## Output

- สำหรับทุกคำสั่ง `0 p` ให้แสดงหมายเลขช่องจอดรถที่ทำการจอด บรรทัดละหนึ่งหมายเลข

## ตัวอย่าง

```
input:
6 3 8
1 2 1 3 2 1
0 1
0 2
0 1
0 1
1 1
0 1
0 3
0 2

output:
1
2
3
6
1
4
5
```

## Limits

- เวลา 1 วินาที, หน่วยความจำ 256 MB
