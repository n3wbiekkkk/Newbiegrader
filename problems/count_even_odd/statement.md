# นับเลขคู่และเลขคี่ (Even Odd Count)

ร้านซักรีดของดิวรับถุงเท้ามาซักเป็นกอง มีป้ายหมายเลขติดอยู่ทุกคู่
เจ้าของร้านอยากจัดโปรโมชัน "หมายเลขคู่ลดราคา หมายเลขคี่แถมน้ำยาปรับผ้านุ่ม"
ดิวเลยต้องนับให้ได้ก่อนว่ามีหมายเลขคู่กี่ตัว เลขคี่กี่ตัว แล้วค่อยไปติดป้ายทีละคู่
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่งเขียนฟังก์ชัน — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดแรก: `n` (1 <= n <= 100)
- บรรทัดที่สอง: จำนวนเต็ม `n` ตัว (-10^6 <= ค่า <= 10^6)

## Output
- บรรทัดเดียว: `Even = จำนวนเลขคู่, Odd = จำนวนเลขคี่` (รูปแบบเป๊ะตามตัวอย่าง)

## ตัวอย่าง
```
input:
5
-3 -2 -1 0 7

output:
Even = 2, Odd = 3
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
