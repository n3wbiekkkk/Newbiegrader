# ตารางการแสดงบนเวที (Stage Schedule)

เจเป็นผู้ดูแลเวทีหลักของงาน มีวงดนตรีส่งใบสมัครมาขอแสดง `N` วง
แต่ละวงแจ้งเวลาเริ่มและเวลาจบ เวทีมีเพียงเวทีเดียว แสดงพร้อมกันไม่ได้
แต่ถ้าวงหนึ่งจบที่เวลา `t` อีกวงเริ่มที่เวลา `t` พอดีได้

ปุนซึ่งเป็นผู้ช่วยอยากให้มีวงขึ้นแสดงให้ได้มากที่สุด เพื่อให้คนดูสนุก
จงหาจำนวนวงมากที่สุดที่ขึ้นแสดงได้

## Input
- บรรทัดแรก: `N` (1 <= N <= 200000)
- อีก `N` บรรทัด: `เวลาเริ่ม` และ `เวลาจบ` (0 <= เวลาเริ่ม < เวลาจบ <= 10^9)

## Output
- บรรทัดเดียว: จำนวนวงมากที่สุด

## ตัวอย่าง
```
input:
5
1 4
3 5
0 6
5 7
8 9

output:
3
```
เรียงตามเวลาจบ เลือกวง (1,4) ต่อด้วย (5,7) แล้วต่อด้วย (8,9) ได้ 3 วง
วง (3,5) และ (0,6) เริ่มก่อนเวลา 4 จึงเลือกไม่ได้

## Subtask
- กลุ่ม 1 (30 คะแนน): N <= 15
- กลุ่ม 2 (70 คะแนน): ไม่มีเงื่อนไขเพิ่มเติม

## Limits
- เวลา 1 วินาที, หน่วยความจำ 256 MB
