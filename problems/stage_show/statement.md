# ตารางการแสดงบนเวที (Stage Schedule)

วงดนตรี `N` วง แต่ละวงแจ้งเวลาเริ่ม-จบ เวทีมีเวทีเดียว
วงที่จบเวลา `t` แล้ววงต่อไปเริ่มเวลา `t` ได้พอดี จงเลือกให้ได้จำนวนวงมากที่สุด

## Input
- บรรทัดแรก: `N` (1 <= N <= 200000)
- อีก N บรรทัด: `เวลาเริ่ม เวลาจบ` (0 <= เริ่ม < จบ <= 10^9)

## Output
- บรรทัดเดียว: จำนวนวงมากที่สุด

## ตัวอย่าง
```
input:
5
1 4
3 5
0 6
5 7
8 9

output:
3
```
(เลือก (1,4), (5,7), (8,9))

## Subtask
- กลุ่ม 1 (30 คะแนน): N <= 15
- กลุ่ม 2 (70 คะแนน): ไม่มีเงื่อนไขเพิ่มเติม

## Limits
- เวลา 1 วินาที, หน่วยความจำ 256 MB
