# เหรียญโอลิมปิก (Olympic Medal)

มีข้อมูล `N` ประเทศ: รหัสประเทศ + เหรียญทอง/เงิน/ทองแดง
จากนั้นรับรหัสสอบถามทีละบรรทัดจนกว่าจะเจอ `0` หรือค่าติดลบ:
- `1001`/`1002`/`1003`: รหัสประเทศที่ได้ทอง/เงิน/ทองแดงมากสุด (หลายประเทศให้เรียงตามลำดับกรอกข้อมูล คั่นช่องว่าง)
- `2000`: รหัสประเทศที่ได้เหรียญรวมมากสุด
- `3000`: รหัสทุกประเทศที่ได้เหรียญอย่างน้อย 1 เหรียญ
- ตรงกับรหัสประเทศ: พิมพ์ `ทอง เงิน ทองแดง รวม`
- เลขอื่น: พิมพ์ `invalid code`
- `0`/ติดลบ: พิมพ์ `good bye` แล้วจบ

## Input
- บรรทัดแรก: `N` (`5 <= N <= 250`)
- อีก `N` บรรทัด: `รหัส ทอง เงิน ทองแดง` (รหัสไม่เกิน 999)
- ที่เหลือ: รหัสสอบถามทีละบรรทัด (ไม่เกิน 100 ครั้ง) จบด้วย `0`/ติดลบ

## Output
- ตอบทีละบรรทัดตามคำถาม
