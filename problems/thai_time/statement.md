# ระบบบอกเวลาภาษาไทย (Thai Time)

ค่ายมีนักเรียนแลกเปลี่ยนที่ฟังภาษาไทยไม่ออก ปุนเลยรับหน้าที่ประกาศเวลาออกเสียงตามสาย
แต่ต้องพูดแบบทับศัพท์ภาษาอังกฤษให้น้องๆ เข้าใจ เช่น บ่าย 1 พูดว่า `Bai 1`
รับชั่วโมง `N` กับช่วงเวลา `S` (`AM`/`PM`) แล้วตอบคำบอกเวลาให้ถูก
ถ้าชั่วโมงไม่อยู่ในช่วง 1–12 ตอบ `invalid`

## Input
- บรรทัดเดียว: `N S` (-1000 <= N <= 1000, `S` เป็น `AM` หรือ `PM`)

## Output
- บรรทัดเดียว: คำบอกเวลาทับศัพท์ หรือ `invalid`

## ตัวอย่าง
```
input:
8 AM

output:
8 Mong Chao
```

การแปลงทั้งหมด:
- `2 AM` → `Ti 2`, `12 AM` → `Thiang Khuen`
- `2 PM` → `Bai 2`, `5 PM` → `5 Mong Yen`
- `8 PM` → `2 Thum`, `12 PM` → `Thiang Whan`
- `15 AM` → `invalid`

## Limits
- เวลา 1 วินาที, หน่วยความจำ 256 MB
