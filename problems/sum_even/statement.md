# ผลรวมของเลขคู่ (Sum Even)

ก้องช่วยยายขายล็อตโต้ที่ตลาดนัดทุกเย็น ตอนปิดแผงต้องสรุปยอดส่งเจ้ามือ
แต่เจ้ามือบอกว่าสนใจแค่ "เลขคู่" เท่านั้น (เลข 0 กับเลขคู่ติดลบก็นับ) เพราะจะเอาไปทำสถิติพิเศษ
ก้องขี้เกียจบวกทีละใบ เลยอยากได้โปรแกรมช่วยรวมผลเฉพาะเลขคู่ให้
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่งเขียนฟังก์ชัน — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดแรก: `n` (1 <= n <= 100)
- บรรทัดที่สอง: จำนวนเต็ม `n` ตัว (-10^6 <= ค่า <= 10^6)

## Output
- บรรทัดเดียว: ผลรวมของจำนวนคู่ (ไม่มีเลยตอบ 0)

## ตัวอย่าง
```
input:
6
-4 -3 0 7 8 -2

output:
2
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
