# สายไบนารีที่ไม่มีเลข 1 ติดกัน (Binary Strings)

ชมรมรหัสลับของดิวออกโจทย์ประจำสัปดาห์: เขียนสายอักขระยาว `n` ตัวจาก 0 กับ 1
"ทุกแบบ" ที่ไม่มีเลข 1 อยู่ติดกัน เรียงตามพจนานุกรม (0 มาก่อน 1)
ใครเขียนครบก่อนโดยไม่ขาดไม่เกินชนะไปเลย ดิวเลยต้องมีเฉลยไว้ตรวจเพื่อน
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- `n` (1 <= n <= 15)

## Output
- สายอักขระบรรทัดละ 1 แบบ แล้วบรรทัดสุดท้ายคือจำนวนแบบทั้งหมด

## ตัวอย่าง
```
input:
2

output:
00
01
10
3
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
