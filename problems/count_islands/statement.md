# นับเกาะ (Count Islands)

โอมได้เกมกระดานใหม่เป็นของขวัญวันเกิด แผนที่ทะเลขนาด `R x C`
ช่อง `#` คือแผ่นดิน ช่อง `.` คือทะเล แผ่นดินที่ติดกัน 4 ทิศ (ไม่นับทแยง) เป็นเกาะเดียวกัน
คู่มือเกมท้าให้หาว่าแผนที่นี้มีกี่เกาะ และเกาะที่ใหญ่ที่สุดมีกี่ช่อง (ไม่มีแผ่นดินเลยตอบ 0 0)
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดแรก: `R C` (1 <= R, C <= 50)
- อีก `R` บรรทัด: ตัวอักษร `#`/`.` บรรทัดละ `C` ตัว

## Output
- บรรทัดเดียว: `จำนวนเกาะ ขนาดเกาะใหญ่สุด`

## ตัวอย่าง
```
input:
5 6
######
#....#
#.##.#
#....#
######

output:
2 18
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
