# รากดิจิทัล (Digital Root)

โอมเห็นพราวเล่นเกมบวกเลขโดดแล้วติดใจ เลยขอกติกาเพิ่มเป็น "รากดิจิทัล"
คือบวกเลขโดดไปเรื่อยๆ จนเหลือหลักเดียว (เช่น 5891 → 23 → 5)
แถมทายเลขสุดท้ายล่วงหน้าว่าจะออกอะไร ใครทายถูกกินขนมเพื่อนทั้งวง
โอมเลยต้องมีโปรแกรมไว้ตรวจว่าเลขสุดท้ายของแต่ละจำนวนคืออะไร
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- จำนวนเต็ม `x` ตัวเดียว (0 <= x <= 10^18)

## Output
- บรรทัดเดียว: เลขหลักเดียวที่ได้

## ตัวอย่าง
```
input:
5891

output:
5
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
