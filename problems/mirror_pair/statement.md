# เลขสะท้อนคู่ (Mirror Pair)

มะลิสะสมธนบัตรเลขสวยเป็นงานอดิเรก แล้วเธอก็ตั้งนิยามใหม่ขึ้นมาเองว่า "เลขสะท้อนคู่"
คือเลขที่อ่านจากสองทางได้เท่ากัน แถมเอาไปยกกำลังสองแล้วยังอ่านสองทางเท่าเดิม (เช่น 11 เพราะ 121 ก็สะท้อน)
เธอท้าเพื่อนว่าในช่วง `a` ถึง `b` มีเลขแบบนี้อยู่กี่ตัว และมีเลขอะไรบ้าง
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่งเขียนฟังก์ชัน — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- `a b` (1 <= a <= b <= 10^6)

## Output
- บรรทัดที่ 1: จำนวนที่พบ
- บรรทัดที่ 2: ตัวเลขเรียงน้อยไปมากคั่นช่องว่าง (ไม่พบเลยไม่ต้องพิมพ์บรรทัดนี้)

## ตัวอย่าง
```
input:
23 100

output:
0
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
- ระวัง: `n^2` อาจถึง 10^12 (แนะนำ 64-bit)
