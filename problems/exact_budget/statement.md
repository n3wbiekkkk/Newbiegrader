# ซื้อของให้พอดีงบ (Exact Budget)

งานวัดประจำปีมีร้านขายของ `n` ร้านราคาต่างกัน ต้นมีเงินติดตัว `S` บาทพอดี
เขาตั้งใจว่าจะซื้อของ (ชิ้นละไม่เกินครั้งเดียว) ให้เงินหมดพอดีไม่เหลือสักบาท
ก่อนเดินเข้าวงาน ต้นอยากรู้ว่ามีกี่วิธีที่จะทำแบบนั้นได้ และในบรรดาวิธีทั้งหมด
วิธีที่ได้ของน้อยชิ้นที่สุดคือกี่ชิ้น (ถ้าไม่มีวิธีเลยตอบ -1)
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดแรก: `n S` (1 <= n <= 20, 1 <= S <= 10^6)
- บรรทัดที่สอง: ราคา `n` ชิ้น (1 <= ราคา <= 100000)

## Output
- บรรทัดที่ 1: จำนวนวิธี
- บรรทัดที่ 2: ชิ้นน้อยสุด (ไม่มีวิธีตอบ -1)

## ตัวอย่าง
```
input:
5 6
1 2 3 4 5

output:
3
2
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
