# หอคอยฮานอย (Hanoi Tower)

เจมีจาน `n` ใบซ้อนที่เสา 1 ต้องย้ายทั้งหมดไปเสา 3 (ผ่านเสาพักเสา 2)
ย้ายได้ครั้งละใบ ห้ามวางใบใหญ่ทับใบเล็ก จงแสดงลำดับการย้ายที่น้อยที่สุด
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- จำนวนจาน `n` (1 <= n <= 10)

## Output
- บรรทัดละ 1 การย้าย: `Move disc d from a to b`
- บรรทัดสุดท้าย: `Total moves: จำนวนครั้ง`

## ตัวอย่าง
```
input:
2

output:
Move disc 1 from 1 to 2
Move disc 2 from 1 to 3
Move disc 1 from 2 to 3
Total moves: 3
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
