# A+B Problem (วอร์มมือ)

รับจำนวนเต็ม 2 ตัว `A B` แล้วพิมพ์ผลบวก

## Input
- บรรทัดเดียว: `A B` โดยที่ `-10^18 <= A, B <= 10^18`

## Output
- บรรทัดเดียว: `A+B`

## ตัวอย่าง
```
input:  2 3
output: 5
```

## กับดักแบบโหด (hidden tests)
- เลขติดลบ, ศูนย์
- ค่าใหญ่สุด `10^18` (ภาษา C/C++ ต้องใช้ `long long`, `int` แตก)
- ช่องว่างแปลกๆ / newline ท้ายไฟล์
- อินพุตมีบรรทัดว่าง
