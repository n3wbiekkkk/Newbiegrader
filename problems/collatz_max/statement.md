# ลำดับคอลลาตซ์ที่ยาวที่สุด (Collatz Max)

ก้องเจอเกมประหลาดจากนิตยสารเก่าในห้องสมุด กติกามีข้อเดียว: เจอเลขคู่ให้หารสอง เจอเลขคี่ให้คูณสามบวกหนึ่ง
ทำซ้ำไปเรื่อยๆ จนเหลือ 1 แล้วนับว่าใช้ไปกี่ครั้ง (`steps(n)`)
เขาเล่นไปหลายเลขแล้วสงสัยว่า ในช่วง `a` ถึง `b` เลขไหนใช้จำนวนครั้งมากสุด (เท่ากันเอาตัวน้อย)
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่งเขียนฟังก์ชัน — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- `a b` (1 <= a <= b <= 10^6, b - a <= 200000)

## Output
- บรรทัดเดียว: `n steps(n)`

## ตัวอย่าง
```
input:
113383 113383

output:
113383 247
```
(ระหว่างทางค่าเกิน int ได้ แนะนำ 64-bit)

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
