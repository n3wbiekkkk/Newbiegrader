# ลำดับคอลลาตซ์ที่ยาวที่สุด (Collatz Max)

ก้องเล่นเกม: เริ่มจาก `n` ถ้าคู่หาร 2 ถ้าคี่คูณ 3 บวก 1 ทำซ้ำจนได้ 1
`steps(n)` คือจำนวนครั้งที่ใช้ จงหา `n` ในช่วง `a` ถึง `b` ที่ steps มากสุด (เท่ากันเอาตัวน้อย)
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่งเขียนฟังก์ชัน — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- `a b` (1 <= a <= b <= 10^6, b - a <= 200000)

## Output
- บรรทัดเดียว: `n steps(n)`

## ตัวอย่าง
```
input:
113383 113383

output:
113383 247
```
(ระหว่างทางค่าเกิน int ได้ แนะนำ 64-bit)

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
