# ถอดรหัสคัมภีร์ (The KAI-GAI Codex)

ในซากโบราณสถานของลัทธิไข่ไก่ นักโบราณคดีค้นพบข้อความจารึกที่ถูกเข้ารหัสด้วย ระบบบีบอัดแบบวงเล็บซ้อนทับ (Nested Multiplier Compression) ซึ่งสาวกโบราณใช้ย่อข้อความสวดมนต์ยาว ๆ ให้สั้นลง รูปแบบข้อความที่รับเข้ามาจะเป็นสตริงที่ประกอบด้วย ตัวอักษร ตัวเลข (0-9) และเครื่องหมายวงเล็บก้ามปู (`[` และ `]`) โดยมีรูปแบบการเข้ารหัส เช่น `2[K3[AI]]` ซึ่งคลี่ออกได้เป็น `KAIAIAIKAIAIAI` (คลี่วงเล็บชั้นในก่อน แล้วค่อยคลี่ชั้นนอก รับประกันว่าวงเล็บเปิด-ปิดถูกต้องเสมอ)

เมื่อคลี่ข้อความออกมาแล้ว จะต้องทำการตรวจสอบพลังศรัทธาของทั้งสองฝ่าย (`KAI` และ `GAI`) ไปพร้อม ๆ กัน โดยไม่จำกัดตัวพิมพ์ใหญ่-เล็ก (Case-insensitive) นิยามคำศักดิ์สิทธิ์:

- คำว่า `KAI`: ตัวอักษร `K/k` ตามด้วย `A/a` และตามด้วย `I/i` อย่างน้อย 1 ตัวติดกัน (เช่น `KAI`, `Kaaii`, `kAAiii`)
- คำว่า `GAI`: ตัวอักษร `G/g` ตามด้วย `A/a` และตามด้วย `I/i` อย่างน้อย 1 ตัวติดกัน (เช่น `GAI`, `Gaaii`, `gAAiiii`)

การนับให้นับจากซ้ายไปขวาไม่ซ้อนทับกัน ความยาวหาง `I` ของแต่ละคำนับรวมตัว `I` ทั้งหมดที่ต่อท้าย (เช่น `KAAIII` มีหางยาว 3)

## Input

- บรรทัดเดียว: ข้อความจารึกที่ถูกบีบอัด ความยาวไม่เกิน 1000 ตัวอักษร ตัวเลขคูณมีค่า 1–999 รับประกันว่าข้อความหลังคลี่แล้วมีความยาวรวมไม่เกิน 1000000 ตัวอักษร

## Output

กรณีที่พบคำว่า `KAI` หรือ `GAI` อย่างน้อยหนึ่งคำ (หรือพบทั้งคู่):

- บรรทัดที่ 1: ความยาวรวมทั้งหมดของข้อความหลังจากคลี่ออกจากวงเล็บ
- บรรทัดที่ 2: จำนวนครั้งที่พบคำว่า `KAI` และความยาวหาง `I` ที่ยาวที่สุด (คั่นด้วยช่องว่าง)
- บรรทัดที่ 3: จำนวนครั้งที่พบคำว่า `GAI` และความยาวหาง `I` ที่ยาวที่สุด (คั่นด้วยช่องว่าง)

กรณีที่ไม่พบทั้ง `KAI` และ `GAI` เลย:

- ถ้าพบตัวอักษร `K/k` หรือ `G/g` แฝงอยู่: บรรทัดที่ 1 แสดงความยาวรวม บรรทัดที่ 2 แสดงข้อความหลังถูกลงทัณฑ์ (ค้นหาตัว `K` หรือ `G` ตัวแรกสุด แล้วแปลงตัวอักษรทุกตัวที่อยู่ข้างหลังให้เป็น `I` พิมพ์ใหญ่ทั้งหมด)
- ถ้าไม่พบทั้งตัวอักษร `K/k` และ `G/g` เลย: บรรทัดที่ 1 แสดงความยาวรวม บรรทัดที่ 2 แสดงข้อความที่สร้างขึ้นใหม่โดยนำ `KAI` และ `GAI` มาต่อสลับกันไปเรื่อย ๆ จนเท่ากับความยาวต้นฉบับ

## ตัวอย่าง

```
input:
2[K2[AI]]1[GAI]

output:
13
2 1
1 1
```

```
input:
3[G2[AI]]

output:
15
0 0
3 1
```

```
input:
2[k2[aI]]1[gAi]

output:
13
2 1
1 1
```

```
input:
2[a2[bk]]

output:
10
abkIIIIIII
```

```
input:
2[a3[x]]

output:
8
KAIGAIKA
```
