# เลือกตั้งประธานชมรมดนตรี (Club Election)

นักเรียน `N` คนลงคะแนนให้ผู้สมัครหมายเลข 1 ถึง 1000
ผู้ชนะคือคะแนนมากสุด ถ้าเท่ากันหมายเลขน้อยกว่าชนะ

## Input
- บรรทัดแรก: `N` (1 <= N <= 200000)
- บรรทัดที่สอง: หมายเลขที่แต่ละคนเลือก (1 <= หมายเลข <= 1000)

## Output
- บรรทัดเดียว: `หมายเลขผู้ชนะ จำนวนคะแนน`

## ตัวอย่าง
```
input:
8
3 1 3 2 1 3 2 2

output:
2 3
```
(หมายเลข 2 กับ 3 ได้ 3 คะแนนเท่ากัน หมายเลขน้อยกว่าชนะ)

## Subtask
- กลุ่ม 1 (40 คะแนน): N <= 100
- กลุ่ม 2 (60 คะแนน): ไม่มีเงื่อนไขเพิ่มเติม

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
