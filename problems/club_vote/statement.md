# เลือกตั้งประธานชมรมดนตรี (Club Election)

ชมรมดนตรีของโรงเรียนมีผู้สมัครประธานหลายคน แต่ละคนมีหมายเลข 1 ถึง 1000
มีนักเรียน `N` คนมาลงคะแนน โดยโตโน่เป็นคนเก็บบัตรลงคะแนน และข้าวปุ้นเป็นคนนับ

ผู้ชนะคือคนที่ได้คะแนนมากที่สุด ถ้ามีคนได้คะแนนเท่ากัน ให้คนที่มีหมายเลขน้อยกว่าชนะ
ปุนซึ่งเป็นครูที่ปรึกษาอยากรู้ผล จงพิมพ์หมายเลขผู้ชนะและจำนวนคะแนนของเขา

## Input
- บรรทัดแรก: `N` (1 <= N <= 200000)
- บรรทัดที่สอง: หมายเลขผู้สมัครที่แต่ละคนเลือก (1 <= หมายเลข <= 1000)

## Output
- บรรทัดเดียว: `หมายเลขผู้ชนะ จำนวนคะแนน` คั่นด้วยช่องว่าง

## ตัวอย่าง
```
input:
8
3 1 3 2 1 3 2 2

output:
2 3
```
หมายเลข 1 ได้ 2 คะแนน, หมายเลข 2 ได้ 3 คะแนน, หมายเลข 3 ได้ 3 คะแนน
เสมอกันที่ 3 คะแนน ผู้ชนะคือหมายเลขน้อยกว่า คือ 2

## Subtask
- กลุ่ม 1 (40 คะแนน): N <= 100
- กลุ่ม 2 (60 คะแนน): ไม่มีเงื่อนไขเพิ่มเติม

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
