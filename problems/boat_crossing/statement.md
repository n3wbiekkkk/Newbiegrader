# เรือพายข้ามคลอง (Boat Rescue)

เรือหนึ่งลำนั่งได้ไม่เกิน 2 คน และน้ำหนักรวมไม่เกิน `W`
มีคน `N` คน (ทุกคนหนักไม่เกิน `W`) จงใช้เรือให้น้อยที่สุด

## Input
- บรรทัดแรก: `N W` (1 <= N <= 200000, 1 <= W <= 10^9)
- บรรทัดที่สอง: น้ำหนักแต่ละคน (1 <= น้ำหนัก <= W)

## Output
- บรรทัดเดียว: จำนวนเรือน้อยที่สุด

## ตัวอย่าง
```
input:
4 3
2 3 1 2

output:
3
```
(3 ไปคนเดียว, 2 + 1, 2 ที่เหลือไปคนเดียว)

## Subtask
- กลุ่ม 1 (30 คะแนน): N <= 15
- กลุ่ม 2 (70 คะแนน): ไม่มีเงื่อนไขเพิ่มเติม

## Limits
- เวลา 1 วินาที, หน่วยความจำ 256 MB
