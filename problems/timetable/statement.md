# ตารางแข่งกีฬา (Tournament Fields)

โรงเรียนต้องจัดการแข่งขันกีฬาหลายประเภทในหนึ่งวัน กีฬาแต่ละประเภทมีเวลาเริ่มต้นและเวลาสิ้นสุด และแต่ละชนิดต้องใช้สนามหนึ่งสนามตั้งแต่เริ่มจนจบ (สนามเดียวกันใช้พร้อมกันสองชนิดไม่ได้ แต่ชนิดหนึ่งจบแล้วชนิดต่อไปเริ่มเวลาเดียวกันได้) จงหาว่าต้องเปิดใช้สนามน้อยที่สุดกี่สนามจึงจะจัดการแข่งขันทั้งหมดได้

## Input

- บรรทัดแรก: จำนวนชุดข้อมูลทดสอบ `t` (1 <= t <= 100)
- ในแต่ละชุด: บรรทัดแรกคือจำนวนกีฬา `n` (1 <= n <= 10000) อีก `n` บรรทัดคือเวลาเริ่ม `s` และเวลาจบ `e` (`0 <= s < e <= 2400`)

## Output

- `t` บรรทัด: จำนวนสนามน้อยที่สุดของแต่ละชุด

## ตัวอย่าง

```
input:
1
3
0800 1000
0830 0930
0935 1030

output:
2
```
