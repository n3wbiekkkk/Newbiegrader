# ย่อภาพผลึกมานา (Mana Crystal)

ตารางพลังงานขนาด `N x N` แบ่งเป็นบล็อกย่อย `K x K` (N หาร K ลงตัวเสมอ)
แต่ละบล็อกยุบเหลือค่าเดียว = ค่าเฉลี่ยของทุกช่องในบล็อก
พิมพ์ตารางผลลัพธ์ขนาด `(N/K) x (N/K)` เรียงซ้ายไปขวา บนลงล่าง

## Input
- บรรทัดแรก: `N` (1 <= N <= 1000)
- อีก N บรรทัด: ตัวเลข N จำนวนต่อบรรทัด (0 <= ค่า <= 10^3)
- บรรทัดสุดท้าย: `K` (1 <= K <= N, N % K == 0)

## Output
- ตาราง `(N/K)` บรรทัด แต่ละบรรทัดมีค่าเฉลี่ยของแต่ละบล็อกคั่นด้วยช่องว่าง 1 ช่อง
- **ล็อกทศนิยม 2 ตำแหน่งเสมอ** (`fixed << setprecision(2)` — เช่น `11.00`, `2.50`)
  พิมพ์ `11` หรือ `11.0` ถือว่าผิดรูปแบบ ได้ WA (แต่ช่องว่างเกินท้ายบรรทัดอนุโลมให้)

## ตัวอย่าง
```
input:
4
8 12 4 16
20 4 8 0
16 24 12 8
4 8 0 4
2

output:
11.00 7.00
13.00 6.00
```

## Subtasks
- 20 คะแนน: N <= 10, K = 1
- 30 คะแนน: N <= 100, K = N
- 50 คะแนน: เต็ม (N <= 1000)
