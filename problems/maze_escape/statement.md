# หนีเขาวงกต (Maze Escape)

งานวัดปีนี้มีซุ้มเขาวงกตยักษ์วางบนตารางขนาด `R x C` ช่อง `.` คือทางเดิน ช่อง `#` คือกำแพง ข้าวปุ้นพลัดหลงเข้าไปตอนตามหาเพื่อน เธอจำแผนที่ได้ว่าตัวเองอยู่ที่ `S` และทางออกอยู่ที่ `E` แต่ละก้าวเดินได้แค่ 4 ทิศ (ขึ้น/ลง/ซ้าย/ขวา) ห้ามเดินทะลุกำแพงและห้ามออกนอกตาราง

ข้าวปุ้นอยากออกให้เร็วที่สุด จงหาจำนวนก้าวที่น้อยที่สุดจาก `S` ถึง `E` ถ้าออกไม่ได้เลยตอบ `-1`

## Input

- บรรทัดแรก: `R C` (1 <= R, C <= 500)
- อีก `R` บรรทัด: แผนที่บรรทัดละ `C` ตัวอักษร (`.`, `#`, `S`, `E`) มี `S` กับ `E` อย่างละหนึ่งช่องเสมอ

## Output

- บรรทัดเดียว: จำนวนก้าวน้อยสุด หรือ `-1` ถ้าไปไม่ถึง

## ตัวอย่าง

```
input:
5 6
S...#.
##.#..
......
.####.
....E.

output:
10
```

```
input:
3 3
S#E
###
...

output:
-1
```

## Limits

- เวลา 1 วินาที, หน่วยความจำ 256 MB
