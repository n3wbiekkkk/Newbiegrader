# หาค่ามากที่สุดด้วยฟังก์ชัน (Find Max)

เปิดเทอมใหม่ มะลิได้รับเลือกเป็นประธานห้อง วันแรกครูให้รวบรวมคะแนนสอบย่อยของเพื่อนทั้งห้อง
เพื่อหาว่าใครได้คะแนนสูงสุดประจำสัปดาห์ คนที่ได้ที่หนึ่งจะได้เป็นตัวแทนห้องไปแข่งตอบปัญหา
มะลิอยากได้คำตอบไวๆ โดยไม่ต้องไล่ดูทีละใบ
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่งเขียนฟังก์ชัน — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดแรก: `n` (1 <= n <= 100)
- บรรทัดที่สอง: จำนวนเต็ม `n` ตัว (-10^9 <= ค่า <= 10^9)

## Output
- บรรทัดเดียว: ค่ามากที่สุด

## ตัวอย่าง
```
input:
5
10 20 30 25 5

output:
30
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
