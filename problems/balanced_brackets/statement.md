# วงเล็บสมดุล (Balanced Brackets)

ในระบบประมวลผลนิพจน์ทางคณิตศาสตร์หรือคอมไพเลอร์ วงเล็บที่ใช้มักมีหลากหลายรูปแบบ ได้แก่ วงเล็บกลม `( )` วงเล็บก้ามปู `[ ]` วงเล็บปีกกา `{ }` และวงเล็บแหลม `< >` นิพจน์ที่มีการเปิดและปิดวงเล็บถูกต้อง (Balanced) จะต้องปฏิบัติตามกฎ 3 ข้อดังนี้

1. จับคู่ตรงชนิด: วงเล็บเปิดชนิดใด ต้องถูกปิดด้วยวงเล็บปิดชนิดเดียวกันเสมอ
2. ลำดับการซ้อนกันถูกต้อง (LIFO): วงเล็บเปิดตัวล่าสุดที่ยังไม่ได้ปิด จะต้องเป็นตัวแรกที่ถูกจับคู่ปิดเสมอ เช่น `[(])` ไม่ถูกต้อง
3. ครบถ้วนสมบูรณ์: ไม่มีวงเล็บปิดที่ไม่มีวงเล็บเปิดมาก่อน และเมื่อสิ้นสุดสตริงต้องไม่มีวงเล็บเปิดใดค้างอยู่

จงเขียนโปรแกรมตรวจสอบสตริงสมการที่ได้รับว่า การเปิด-ปิดวงเล็บทุกชนิดเป็นไปตามหลักการหรือไม่ (ตัวอักษรอื่นที่ไม่ใช่วงเล็บทั้ง 8 ตัวให้มองข้ามไป)

## Input

- ข้อมูลนำเข้าประกอบด้วยสตริง 1 บรรทัดขึ้นไป บรรทัดละหนึ่งนิพจน์ ความยาวต่อบรรทัด `1 <= |S| <= 100000` ตัวอักษร Printable ASCII (รหัส 32–126)

## Output

- ตอบบรรทัดละหนึ่งคำต่อหนึ่งนิพจน์นำเข้า: `Yes` ถ้าวงเล็บถูกต้องทั้งหมด ไม่เช่นนั้นตอบ `No`

## ตัวอย่าง

```
input:
[(x + 2) * {y - 1}] / <z + 3>

output:
Yes
```

```
input:
([a + b)]

output:
No
```

```
input:
{<x + 2>} > 10

output:
No
```

## Limits

- เวลา 1 วินาที, หน่วยความจำ 256 MB
