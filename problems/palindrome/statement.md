# Palindrome (เช็ค string)

รับสตริง 1 บรรทัด แล้วตอบว่าเป็น palindrome หรือไม่ (อ่านหน้า-หลังเหมือนกัน)

## Input
- 1 บรรทัด ความยาว `0 <= len <= 10^6`
- ตัวอักษรเป็น ASCII ที่พิมพ์ได้ อาจมีช่องว่าง
- **case-sensitive**: `Aa` ไม่ใช่ palindrome

## Output
- `YES` ถ้าใช่, `NO` ถ้าไม่ใช่

## ตัวอย่าง
```
input:  racecar
output: YES
```

## กับดักแบบโหด
- สตริงว่าง → `YES`
- ตัวเดียว → `YES`
- `Aa` → `NO` (ห้ามแปลง case มั่ว)
- สตริงยาว 10^6 (`a...a` + `b` ตรงกลาง) → โค้ด `s == s[::-1]` ผ่าน แต่ `O(n^2)` แตก
- ช่องว่างนับเป็นตัวอักษร (`nurses run` → `NO`)
