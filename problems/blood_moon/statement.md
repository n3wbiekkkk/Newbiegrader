# คืนพระจันทร์สีเลือด (Blood Moon)

มีชาวบ้าน N คนเรียงแถว แต่ละคนมีพลัง `a[i]`
ทำพิธีด้วย "จี้" 2 เส้นชี้หัวแถวกับหางแถว แล้วบีบเข้าหากัน:
- ถ้าผลรวมของ 2 คนที่ชี้อยู่เป็น**คู่** → สลับตำแหน่งกัน
- ถ้าเป็น**คี่** → ทั้งคู่พลัง +1
- แล้วขยับจี้เข้าหากันข้างละ 1 คน ทำซ้ำจนจี้ชนกันหรือสวนกัน

**ข้อนี้ใช้ภาษา/วิธีใดก็ได้** (ต้นฉบับ PDF สั่งเติมฟังก์ชันด้วย pointer — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดแรก: `n` (1 <= n <= 10^5)
- บรรทัดที่สอง: `a[1..n]` (1 <= a[i] <= 10^9)

## Output
- บรรทัดเดียว: แถวสุดท้ายหลังพิธี คั่นด้วยช่องว่าง

## ตัวอย่าง
```
input:
5
2 5 9 3 10

output:
10 3 9 5 2
```
