# เพิ่มสินค้าลงชั้นตามช่วงที่กำหนด (shelf_stock)

คลังมีชั้นวาง `N` ชั้น หมายเลข `1` ถึง `N` เริ่มต้นทุกชั้นว่าง (มีสินค้า `0` ชิ้น)
มีคำสั่งเพิ่มสินค้า `Q` คำสั่ง แต่ละคำสั่งให้ค่า `L R V` หมายถึง
เพิ่มสินค้า "ชั้นละ `V` ชิ้น" ตั้งแต่ชั้น `L` ถึงชั้น `R` รวมทั้งสองปลาย
สินค้าเดิมไม่ถูกนำออก ชั้นที่อยู่ในหลายคำสั่งจะได้รับสินค้าเพิ่มสะสมทุกครั้ง

หลังทำครบทุกคำสั่ง จงแสดงจำนวนสินค้าสุดท้ายของชั้นที่ `1` ถึง `N`

## Input
- บรรทัดที่ 1: `N Q`
- อีก `Q` บรรทัด: `L R V` เรียงตามคำสั่งที่ได้รับ

## Output
- บรรทัดเดียว: จำนวนสินค้าของชั้นที่ `1` ถึง `N` คั่นแต่ละค่าด้วยช่องว่าง

## ตัวอย่าง
```
input:
5 3
1 3 2
2 5 1
4 4 3

output:
2 3 3 4 1
```
อธิบาย: หลังคำสั่ง `1 3 2` ได้ `2 2 2 0 0`
หลังคำสั่ง `2 5 1` ได้ `2 3 3 1 1`
หลังคำสั่ง `4 4 3` ได้ `2 3 3 4 1` (คำสั่งสุดท้ายเพิ่ม `3` ชิ้นให้ชั้น `4` เพียงชั้นเดียว)

## Constraints
- `1 <= N, Q <= 200000`
- `1 <= L <= R <= N`
- `1 <= V <= 10^9` (ผลรวมอาจเกิน 32 บิต ต้องใช้ 64 บิต)

## Subtasks
- 30 คะแนน: `N, Q <= 1000`
- 70 คะแนน: เต็ม (วิธีทำทีละชั้นทีละคำสั่งจะช้าเกิน ต้องหาวิธีที่เร็วกว่า)
