# บันไดขั้นพัง (Broken Stairs)

สะพานไม้ข้ามคลองหลังโรงเรียนผุพังไปหลายขั้น ครูเลยสั่งห้ามเหยียบขั้นที่พังเด็ดขาด
พราวต้องข้ามไปอีกฝั่งให้ได้ เธอก้าวได้ครั้งละ 1, 2 หรือ 3 ขั้น จากพื้น (ขั้น 0) ไปให้ถึงขั้น `n` พอดี
ก่อนก้าวจริง เธออยากรู้ก่อนว่ามีวิธีข้ามทั้งหมดกี่แบบ (ถ้าข้ามไม่ได้เลยตอบ 0)
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดแรก: `n k` (1 <= n <= 50, 0 <= k < n, ขั้นพังอยู่ 1..n-1)
- บรรทัดที่สอง (มีเฉพาะเมื่อ k > 0): ขั้นที่พัง `k` ค่าไม่ซ้ำกัน

## Output
- บรรทัดเดียว: จำนวนวิธี

## ตัวอย่าง
```
input:
5 1
2

output:
5
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
