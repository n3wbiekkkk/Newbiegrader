# รีรีข้าวสาร (Josephus)

ครูไก่พานักเรียนตั้งแถวเล่นเกม รีรีข้าวสาร โดยมีเด็กทั้งหมด `N` คน ยืนเรียงเป็นวงกลมและกำหนดหมายเลขประจำตัวตั้งแต่ 1 ถึง `N` กติกาคือ เริ่มนับจากคนที่ 1 วนไปตามวงกลม เมื่อนับไปจนถึงคนที่ `K` คนนั้นจะถูกจับออกจากแถวทันที จากนั้นจะเริ่มนับคนถัดไปจากคนที่ถูกจับออกนับต่อไปอีก `K` คน วนซ้ำแบบนี้ไปเรื่อย ๆ จนกระทั่งเหลือเด็กคนสุดท้ายที่เป็นผู้รอดชีวิต จงหาหมายเลขประจำตัวของคนสุดท้าย

## Input

- จำนวนเต็มสองจำนวน `N K` (1 <= N, K <= 10000) อาจอยู่บรรทัดเดียวกันหรือคนละบรรทัดก็ได้

## Output

- บรรทัดเดียว: หมายเลขประจำตัวของคนสุดท้ายที่รอด

## ตัวอย่าง

```
input:
5 2

output:
3
```

```
input:
4 5

output:
2
```

## Limits

- เวลา 1 วินาที, หน่วยความจำ 64 MB
