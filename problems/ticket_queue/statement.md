# คิวซื้อตั๋วคอนเสิร์ต (Ticket Queue)

หน้าบูธขายตั๋วคอนเสิร์ตของนิวมีคนมาต่อแถวยาวเหยียด
ข้าวปั้นเป็นคนควบคุมคิว คนมาใหม่ต้องไปต่อท้ายแถว
ส่วนคนที่ถูกเรียกไปซื้อตั๋วคือคนที่อยู่หน้าสุดของแถว

ข้าวปั้นจดคำสั่งไว้ 2 แบบ คือ `1 x` หมายถึงคนที่มีหมายเลขบัตรคิว `x` มาต่อท้ายแถว
และ `2` หมายถึงเรียกคนหน้าสุดของแถวไปซื้อตั๋ว (ให้พิมพ์หมายเลขของคนนั้น ถ้าไม่มีใครอยู่ในแถวเลยให้พิมพ์ -1)

## Input
- บรรทัดแรก: `Q` จำนวนคำสั่ง (1 <= Q <= 200000)
- อีก `Q` บรรทัด: คำสั่ง (`1 x` โดย 1 <= x <= 10^9, หรือ `2`)

## Output
- ผลของทุกคำสั่งแบบ `2` บรรทัดละหนึ่งคำตอบ

## ตัวอย่าง
```
input:
7
1 5
1 8
2
1 3
2
2
2

output:
5
8
3
-1
```
คนที่ 5 และ 8 ต่อแถว เรียกคนแรกได้ 5 คนที่ 3 มาต่อท้าย
เรียกได้ 8 แล้วเรียกได้ 3 ส่วนคำสั่งสุดท้ายแถวว่างแล้ว จึงตอบ -1

## Subtask
- กลุ่ม 1 (40 คะแนน): Q <= 1000
- กลุ่ม 2 (60 คะแนน): ไม่มีเงื่อนไขเพิ่มเติม

## Limits
- เวลา 1 วินาที, หน่วยความจำ 256 MB
