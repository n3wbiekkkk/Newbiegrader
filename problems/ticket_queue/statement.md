# คิวซื้อตั๋วคอนเสิร์ต (Ticket Queue)

จำลองแถวคิว 2 คำสั่ง: `1 x` = คนหมายเลข `x` ต่อท้ายแถว,
`2` = เรียกคนหน้าสุดไปซื้อตั๋ว (พิมพ์หมายเลข ถ้าแถวว่างพิมพ์ -1)

## Input
- บรรทัดแรก: `Q` (1 <= Q <= 200000)
- อีก Q บรรทัด: คำสั่ง (`1 x` โดย 1 <= x <= 10^9, หรือ `2`)

## Output
- ทุกคำสั่งแบบ 2: พิมพ์คำตอบบรรทัดละหนึ่งค่า

## ตัวอย่าง
```
input:
7
1 5
1 8
2
1 3
2
2
2

output:
5
8
3
-1
```

## Subtask
- กลุ่ม 1 (40 คะแนน): Q <= 1000
- กลุ่ม 2 (60 คะแนน): ไม่มีเงื่อนไขเพิ่มเติม

## Limits
- เวลา 1 วินาที, หน่วยความจำ 256 MB
