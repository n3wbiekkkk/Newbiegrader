# Napprime (นับจำนวนเฉพาะ)

นับจำนวนของจำนวนเฉพาะทั้งหมดตั้งแต่ `l` ถึง `r`

## Input
- บรรทัดเดียว: `l r` (1 <= l, r <= 10^6)

## Output
- บรรทัดเดียว: จำนวนเฉพาะในช่วง `[l, r]`

## ตัวอย่าง
```
input:
12 28

output:
4
```
(13, 17, 19, 23)

## Subtasks
- 50 คะแนน: l = r
- 20 คะแนน: l, r <= 10^3
- 30 คะแนน: เต็ม (<= 10^6)

## Limits
- เวลา 0.5 วินาที, หน่วยความจำ 32 MB
