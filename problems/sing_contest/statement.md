# อันดับประกวดร้องเพลง (Singing Contest)

เทศกาลดนตรีริมคลองปีนี้ นิวเป็นผู้จัดงานและเชิญผู้เข้าแข่งขันร้องเพลงมา `N` คน
แต่ละคนมีหมายเลขประจำตัวและคะแนนรวมจากกรรมการ ซึ่งมีเจ ติงลี่ และโตโน่เป็นผู้ให้คะแนน

พอการแข่งขันจบ ข้าวปั้นที่ทำหน้าที่เลขาต้องประกาศอันดับบนเวที
โดยเรียงจากคะแนนมากไปน้อย ถ้ามีคนคะแนนเท่ากัน ให้คนที่หมายเลขน้อยกว่าได้อันดับก่อน
ปุนซึ่งเป็นพิธีกรอยากได้รายชื่อหมายเลขเรียงตามอันดับไว้อ่านบนเวที

## Input
- บรรทัดแรก: `N` (1 <= N <= 100000)
- อีก `N` บรรทัด: `หมายเลข คะแนน` (หมายเลขประจำตัวไม่ซ้ำกัน, 1 <= หมายเลข <= 10^9, 0 <= คะแนน <= 1000000)

## Output
- บรรทัดเดียว: หมายเลขประจำตัวเรียงตามอันดับ คั่นด้วยช่องว่าง

## ตัวอย่าง
```
input:
5
1 80
2 95
3 80
4 70
5 95

output:
2 5 1 3 4
```
คะแนน 95 มีหมายเลข 2 และ 5 (2 มาก่อน), คะแนน 80 มีหมายเลข 1 และ 3 (1 มาก่อน), คะแนน 70 คือหมายเลข 4

## Subtask
- กลุ่ม 1 (40 คะแนน): N <= 100
- กลุ่ม 2 (60 คะแนน): ไม่มีเงื่อนไขเพิ่มเติม

## Limits
- เวลา 1 วินาที, หน่วยความจำ 256 MB
