# อันดับประกวดร้องเพลง (Singing Contest)

ผู้เข้าแข่งขัน `N` คน แต่ละคนมีหมายเลขประจำตัวและคะแนน
ประกาศอันดับโดยเรียงคะแนนมากไปน้อย ถ้าคะแนนเท่ากันให้หมายเลขน้อยกว่าอยู่ก่อน

## Input
- บรรทัดแรก: `N` (1 <= N <= 100000)
- อีก N บรรทัด: `หมายเลข คะแนน` (หมายเลขไม่ซ้ำกัน, 1 <= หมายเลข <= 10^9, 0 <= คะแนน <= 1000000)

## Output
- บรรทัดเดียว: หมายเลขเรียงตามอันดับ คั่นด้วยช่องว่าง

## ตัวอย่าง
```
input:
5
1 80
2 95
3 80
4 70
5 95

output:
2 5 1 3 4
```

## Subtask
- กลุ่ม 1 (40 คะแนน): N <= 100
- กลุ่ม 2 (60 คะแนน): ไม่มีเงื่อนไขเพิ่มเติม

## Limits
- เวลา 1 วินาที, หน่วยความจำ 256 MB
