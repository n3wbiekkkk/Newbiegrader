# ระยะทางรวมน้อยสุด (Min Distance)

มีบ้านเพื่อน N หลังที่พิกัด `a[1..N]` (เรียงจากน้อยไปมาก)
เลือกรวมตัวที่บ้านหลังใดหลังหนึ่ง ให้ผลรวมระยะทางทุกคนมาน้อยที่สุด
ตอบระยะทางรวมนั้น (อาจเกิน int — ใช้ 64-bit)

## Input
- บรรทัดแรก: `n` (1 <= n <= 10^6)
- บรรทัดที่สอง: `a[1]..a[N]` (1 <= a[i] <= a[i+1] <= 10^9)

## Output
- บรรทัดเดียว: ระยะทางรวมน้อยสุด

## ตัวอย่าง
```
input:
5
1 2 4 7 10

output:
14
```
(รวมตัวที่บ้านหลังที่ 3: 3+2+0+3+6 = 14)

## Subtasks
- 50 คะแนน: n <= 10^3
- 50 คะแนน: เต็ม

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
