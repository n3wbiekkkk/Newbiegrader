# ค่าต่ำสุดและผลรวมของอาร์เรย์ (Array Min Sum)

ค่ายฤดูร้อนให้นักเรียน `n` กลุ่มย่อยแข่งกันทำอาหาร แต่ละกลุ่มเบิกงบไปไม่เท่ากัน
ปุนในฐานะเหรัญญิกต้องสรุปให้ครูดูสองอย่าง: กลุ่มไหนเบิกน้อยที่สุด และงบรวมทั้งหมดเท่าไร
บิลมีเป็นปึก ปุนเลยอยากได้โปรแกรมช่วยหาค่าต่ำสุดกับผลรวมในครั้งเดียว
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion ห้ามลูป — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดแรก: `n` (1 <= n <= 1000)
- บรรทัดที่สอง: จำนวนเต็ม `n` ตัว (-10^6 <= ค่า <= 10^6)

## Output
- บรรทัดที่ 1: ค่าต่ำสุด
- บรรทัดที่ 2: ผลรวม

## ตัวอย่าง
```
input:
5
12 15 7 20 30

output:
7
84
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
