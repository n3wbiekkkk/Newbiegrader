# ยกกำลังด้วยการเรียกตัวเอง (Power)

ติงลี่อาสาช่วยครูตรวจการบ้านเลขยกกำลังทั้งห้อง แต่เครื่องคิดเลขของห้องพังพร้อมกันสามเครื่อง
แถมครูสั่งห้ามใช้ฟังก์ชันสำเร็จรูปอย่าง `pow()` เพราะอยากให้เด็กฝึกคิดเอง
ติงลี่เลยต้องเขียนโปรแกรมคำนวณ `a` ยกกำลัง `b` ขึ้นมาใช้เอง
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- `a b` คั่นช่องว่าง (-10 <= a <= 10, 0 <= b <= 18, คำตอบอยู่ในช่วง long long เสมอ)

## Output
- บรรทัดเดียว: ค่า `a^b`

## ตัวอย่าง
```
input:
-3 3

output:
-27
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
