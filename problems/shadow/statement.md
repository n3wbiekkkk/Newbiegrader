# เงาปะทะมังกร (Shadow)

ทหารเงา N ตัวเรียงแถว มังกร M ตัวบุกทีละตัว
มังกรแต่ละตัว: เรียกทหารเงาจากหน้าสุดมาสมทบทีละตัวจนผลรวม >= พลังมังกร
ทหารที่ใช้แล้วหมดแรง (ส่วนเกินทิ้ง) ตัวถัดไปรับมังกรตัวต่อไป
ถ้าเงาหมดก่อนกำจัดครบ ตอบ `No` ไม่งั้น `Yes`

## Input
- บรรทัดแรก: `N M` (1 <= M <= N <= 100000)
- บรรทัดที่สอง: `S[1..N]` (1 <= ค่า <= 10^9)
- บรรทัดที่สาม: `D[1..M]` (1 <= ค่า <= 10^9)

## Output
- `Yes` ถ้ากำจัดครบ ไม่งั้น `No`

## ตัวอย่าง
```
input:
5 2
2 3 1 4 2
4 5

output:
Yes
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
