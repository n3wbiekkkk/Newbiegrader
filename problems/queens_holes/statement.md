# ราชินีบนกระดานมีหลุม (Queens Holes)

กระดาน `N x N` มีช่องปกติ (`.`) กับหลุม (`#`) วางราชินีไม่ได้
วางราชินีให้ครบ `N` ตัวแถวละตัว โดยไม่กินกันเอง (หลุมไม่บังการโจมตี)
จงนับวิธีทั้งหมด และแสดงวิธีน้อยสุดตามพจนานุกรม (เลขคอลัมน์นับจาก 1) ไม่มีวิธีตอบ `NONE`
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดแรก: `N` (1 <= N <= 10)
- อีก `N` บรรทัด: ตัวอักษร `.`/`#` บรรทัดละ `N` ตัว

## Output
- บรรทัดแรก: จำนวนวิธี
- บรรทัดที่สอง: วิธีน้อยสุดคั่นช่องว่าง หรือ `NONE`

## ตัวอย่าง
```
input:
3
...
...
...

output:
0
NONE
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
