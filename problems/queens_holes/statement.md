# ราชินีบนกระดานมีหลุม (Queens Holes)

ชมรมหมากรุกของนิวจัดแข่งแก้ปริศนาประจำเดือน กระดานขนาด `N x N`
มีทั้งช่องปกติ (`.`) กับ "หลุม" (`#`) ที่วางราชินีไม่ได้
กติกาคือวางราชินีให้ครบ `N` ตัว แถวละตัว โดยไม่มีตัวไหนกินกันเอง
(หลุมไม่บังการโจมตี อยู่แนวเดียวกันถือว่ากินกัน) จงนับว่ามีกี่วิธี
และหาวิธีที่มาก่อนตามพจนานุกรม (เขียนเป็นเลขคอลัมน์แถวที่ 1 ถึง N) ไม่มีวิธีตอบ `NONE`
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดแรก: `N` (1 <= N <= 10)
- อีก `N` บรรทัด: ตัวอักษร `.`/`#` บรรทัดละ `N` ตัว

## Output
- บรรทัดแรก: จำนวนวิธี
- บรรทัดที่สอง: วิธีน้อยสุดคั่นช่องว่าง หรือ `NONE`

## ตัวอย่าง
```
input:
3
...
...
...

output:
0
NONE
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
