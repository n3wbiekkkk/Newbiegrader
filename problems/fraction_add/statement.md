# บวกเศษส่วนให้เป็นเศษส่วนอย่างต่ำ (Fraction Add)

แพรช่วยแม่ทำขนมขายตลาดนัด สูตรขนมใช้แป้งหลายส่วนผสมที่เขียนเป็นเศษส่วน
ก่อนไปซื้อของ แพรต้องรวมเศษส่วนทั้งหมด `N` จำนวนให้เป็นเศษส่วนอย่างต่ำ `P/Q` เสียก่อน
(`Q > 0` เสมอ ผลบวกเป็น 0 ตอบ `0/1` เป็นจำนวนเต็ม `k` ตอบ `k/1`)
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่งเขียนฟังก์ชัน — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดแรก: `N` (1 <= N <= 20)
- อีก `N` บรรทัด: `p q` (-100 <= p <= 100, 1 <= q <= 20)

## Output
- บรรทัดเดียว: `P/Q`

## ตัวอย่าง
```
input:
3
3 4
-5 6
1 12

output:
0/1
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
