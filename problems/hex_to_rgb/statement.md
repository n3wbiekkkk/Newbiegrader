# รหัสสีไฟประดับ (Hex to RGB)

งานเทศกาลประจำปีกำลังจะมาถึง ติงลี่ได้รับมอบหมายให้คุมไฟประดับรอบเวทีใหญ่ ร้านขายหลอดไฟส่งแคตตาล็อกมาให้เลือกหลายร้อยสี แต่รหัสสีในแคตตาล็อกเขียนแบบที่ใช้กันบนเว็บ เช่น `#FF0000` ส่วนกล่องคอนโทรลเลอร์ของเวทีรับได้แค่ตัวเลขแยกสามช่อง คือค่าความสว่างของแสงสีแดง เขียว และน้ำเงิน (อย่างละ 0–255)

ยิ่งไปกว่านั้น แต่ละร้านเขียนรหัสไม่เหมือนกันเลย บางร้านเขียนแบบย่อ 3 หลัก (`#0F0` หมายถึง `#00FF00` คือเอาตัวอักษรแต่ละตัวซ้ำสองครั้ง) บางร้านลืมใส่เครื่องหมาย `#` มาข้างหน้า บางร้านใช้ตัวพิมพ์เล็ก บางร้านใช้ตัวพิมพ์ใหญ่ ติงลี่ต้องกรอกค่าลงคอนโทรลเลอร์หลายร้อยสีด้วยมือคงไม่ไหวแน่ จงเขียนโปรแกรมแปลงรหัสสีทั้งล็อตให้ที

## Input

- บรรทัดแรก: จำนวนรหัสสี `N` (1 <= N <= 1000)
- อีก `N` บรรทัด: รหัสสีบรรทัดละหนึ่งรหัส รูปแบบคือเครื่องหมาย `#` (มีหรือไม่มีก็ได้) ตามด้วยเลขฐานสิบหก 6 หลัก (`RRGGBB`) หรือ 3 หลักแบบย่อ (`RGB` ซึ่งหมายถึง `RRGGBB`) ตัวอักษร `0-9`, `A-F` ใช้ตัวพิมพ์เล็กหรือใหญ่ก็ได้

## Output

- `N` บรรทัด บรรทัดละ `R G B` คือค่าฐานสิบของช่องสีแดง เขียว และน้ำเงิน (0–255) คั่นด้วยช่องว่าง

## ตัวอย่าง

```
input:
3
#FF0000
#0F0
00FF00

output:
255 0 0
0 255 0
0 255 0
```

```
input:
4
#ffffff
#000000
abc
#1a2B3c

output:
255 255 255
0 0 0
170 187 204
26 43 60
```

## Limits

- เวลา 1 วินาที, หน่วยความจำ 64 MB
