# อ่างเก็บน้ำ (Trapped Rain Water)

ณ หุบเขาแห่งหนึ่ง มีแนวเสาหินโบราณจำนวน `N` ต้นตั้งเรียงหน้ากระดานติดกัน โดยเสาหินแต่ละต้นมีความสูงแตกต่างกันไป เมื่อเกิดฝนตกหนัก น้ำฝนจะไหลมารองขังอยู่ตามซอกระหว่างเสาหินเหล่านั้น สภาเมืองต้องการให้คุณเขียนโปรแกรมคำนวณหา ปริมาตรน้ำฝนรวมทั้งหมด ที่สามารถกักเก็บไว้ได้ระหว่างซอกเสาหิน โดยมีกฎทางฟิสิกส์คือก้อนน้ำจะถูกกักขังอยู่ได้ก็ต่อเมื่อมีเสาหินที่สูงกว่ากั้นอยู่ทั้งด้านซ้ายและด้านขวา และน้ำจะล้นออกด้านข้างหากไม่มีเสาที่สูงพอค้ำยัน

## Input

- บรรทัดแรก: จำนวนเต็ม `N` (1 <= N <= 100000)
- บรรทัดที่สอง: ความสูงของเสาหิน `N` ต้น (แต่ละต้น `0 <= h <= 10^9`)

## Output

- บรรทัดเดียว: ปริมาตรน้ำฝนที่กักเก็บได้ทั้งหมด

## ตัวอย่าง

```
input:
12
0 1 0 2 1 0 1 3 2 1 2 1

output:
6
```

```
input:
10
5 1 4 2 3 1 4 2 5 1

output:
18
```

## Limits

- เวลา 1 วินาที, หน่วยความจำ 256 MB
