# รหัสผ่านเซิร์ฟเวอร์ สอวน. (POSN Passcode)

รับจำนวนเต็มบวก `N` แล้วหาตัวหารเฉพาะที่ไม่ซ้ำกัน (distinct prime factors) ของ N
พิมพ์จำนวนตัว แล้วพิมพ์แต่ละตัวจากน้อยไปมาก

## Input
- บรรทัดเดียว: `N` (1 <= N <= 10^12)

## Output
- บรรทัดแรก: `K` = จำนวนตัวหารเฉพาะที่ไม่ซ้ำ (N = 1 ตอบ 0 บรรทัดเดียวจบ)
- อีก K บรรทัด: ค่าแต่ละตัวน้อยไปมาก

## ตัวอย่าง
```
input:  12
output:
2
2
3
```

## Subtasks
- 15 คะแนน: N <= 100
- 35 คะแนน: N <= 10^6
- 50 คะแนน: เต็ม (N <= 10^12)

## กับดัก
- N = 1 ตอบ `0` (ไม่มี prime factor)
- N เป็น prime ใหญ่ใกล้ 10^12 — ลองหารทีละตัวถึง sqrt(N) ใน Python โดน TLE (ใช้ sieve + trial division หรือ Pollard-Rho)
- อย่าพิมพ์ตัวซ้ำ (12 = 2^2 x 3 ตอบแค่ 2 ตัว)
