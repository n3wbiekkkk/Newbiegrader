# FizzBuzz (เช็ค loop)

รับ `N` แล้วพิมพ์ 1..N บรรทัดละตัว:
- หาร 3 และ 5 ลงตัว → `FizzBuzz`
- หาร 3 ลงตัว → `Fizz`
- หาร 5 ลงตัว → `Buzz`
- ไม่งั้นพิมพ์เลขนั้น

## Input
- บรรทัดเดียว: `1 <= N <= 100000`

## Output
- `N` บรรทัด

## ตัวอย่าง (N=5)
```
1
2
Fizz
4
Buzz
```

## กับดักแบบโหด
- `N=1` (เล็กสุด), `N=15` (จุด FizzBuzz แรก)
- ตัวพิมพ์ใหญ่-เล็กต้องเป๊ะ (`fizz` ≠ `Fizz` → WA)
- ช่องว่างท้ายบรรทัด → WA (checker แบบ exact)
- `N` ใหญ่ (100000) → โค้ดช้า/ต่อ string โง่ๆ อาจ TLE
