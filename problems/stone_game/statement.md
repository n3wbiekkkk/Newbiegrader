# เกมลูกหิน (Stone Game)

เกมลูกหินเล่นบนกระดานที่มีรูเล็ก ๆ 12 รูเรียงกันเป็นแถว 1 แถว แต่ละรูมีลูกหินอยู่หรือไม่ก็ได้ การย้ายทำได้เมื่อมีรูสามรูติดกันเป็นเส้นตรง สมมติว่าเป็นรู `A B C` โดยที่ `B` อยู่ตรงกลาง รู `A` ว่าง แต่รู `B` และรู `C` มีลูกหิน การย้ายประกอบด้วยการย้ายลูกหินจากรู `C` ไปรู `A` และนำลูกหินในรู `B` ออกจากกระดาน (ย้ายจากซ้ายไปขวาหรือขวามาซ้ายก็ได้) ย้ายต่อไปได้จนกว่าจะย้ายไม่ได้อีก

ภารกิจของคุณคือค้นหาลำดับการย้ายที่ทำให้เหลือลูกหินบนกระดานน้อยที่สุดเท่าที่จะเป็นไปได้

## Input

- บรรทัดแรก: จำนวนกระดาน `N` (1 <= N <= 200)
- อีก `N` บรรทัด: กระดานละหนึ่งบรรทัด เป็นอักขระ 12 ตัว (`-` คือรูว่าง `o` คือมีลูกหิน)

## Output

- `N` บรรทัด: จำนวนลูกหินที่เหลือน้อยที่สุดของแต่ละกระดาน

## ตัวอย่าง

```
input:
2
o----o------
--o-o--o----

output:
2
3
```

## Limits

- เวลา 1 วินาที, หน่วยความจำ 256 MB
