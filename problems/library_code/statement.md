# ซ่อมรหัสสมาชิกห้องสมุด (Library Code)

บัตรสมาชิกห้องสมุดมี 13 หลัก หลักสุดท้ายเป็นตัวตรวจสอบ:
`S = d1x13 + d2x12 + ... + d12x2` แล้วหลักตรวจสอบ = `(11 - (S mod 11)) mod 10`
บัตรบางใบเลือน 1 หลัก (แทนด้วย `?`) จงหาว่าเติมเลขอะไรได้บ้างให้รหัสถูกต้อง
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่งเขียนฟังก์ชัน — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดแรก: `Q` (1 <= Q <= 100)
- อีก `Q` บรรทัด: รหัสยาว 13 ตัวอักษร (ตัวเลข + `?` ไม่เกิน 1 ตัว)

## Output
- `Q` บรรทัดตามลำดับ:
  - ไม่มี `?`: `VALID` หรือ `INVALID`
  - มี `?`: เลขที่ใช้ได้ทุกตัวน้อยไปมากคั่นช่องว่าง ไม่มีเลยตอบ `NONE`

## ตัวอย่าง
```
input:
4
1234567890121
1234567890123
123456789012?
12?4567890122

output:
VALID
INVALID
1
NONE
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
