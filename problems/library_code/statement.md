# ซ่อมรหัสสมาชิกห้องสมุด (Library Code)

ฟ้าเป็นบรรณารักษ์ห้องสมุดโรงเรียน เปิดเทอมนี้มีบัตรสมาชิกใหม่เป็นปึก
แต่บัตรบางใบหมึกเลือนจนอ่านไม่ออก 1 หลัก (แทนด้วย `?`)
โชคดีที่รหัส 13 หลักมีสูตรตรวจสอบในตัว ฟ้าเลยต้องหาว่าหลักที่หายไปเติมเลขอะไรได้บ้างให้รหัสถูกต้อง
(ถ้าไม่มี `?` ก็แค่ตอบว่าถูกหรือผิด ถ้ามีให้บอกทุกเลขที่ใช้ได้ ไม่มีเลยตอบ `NONE`)
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่งเขียนฟังก์ชัน — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดแรก: `Q` (1 <= Q <= 100)
- อีก `Q` บรรทัด: รหัสยาว 13 ตัวอักษร (ตัวเลข + `?` ไม่เกิน 1 ตัว)

## Output
- `Q` บรรทัดตามลำดับ:
  - ไม่มี `?`: `VALID` หรือ `INVALID`
  - มี `?`: เลขที่ใช้ได้ทุกตัวน้อยไปมากคั่นช่องว่าง ไม่มีเลยตอบ `NONE`

## ตัวอย่าง
```
input:
4
1234567890121
1234567890123
123456789012?
12?4567890122

output:
VALID
INVALID
1
NONE
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
