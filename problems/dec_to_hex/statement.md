# แปลงเลขฐานสิบเป็นฐานสิบหก (Decimal to Hex)

เชนเขียนโค้ดสีต้องแปลงเลขฐานสิบเป็นฐานสิบหก (ใช้ A–F พิมพ์ใหญ่ ไม่มี 0 นำหน้า ยกเว้น 0)
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- จำนวนเต็ม `n` ตัวเดียว (0 <= n <= 10^15)

## Output
- บรรทัดเดียว: เลขฐานสิบหก

## ตัวอย่าง
```
input:
1029301932312

output:
EFA72D1118
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
