# แปลงเลขฐานสิบเป็นฐานสิบหก (Decimal to Hex)

เชนรับหน้าที่ออกแบบโปสเตอร์งานเทศกาลประจำปี โปรแกรมวาดรูปของเขาแก่จัด
รับค่าสีได้แค่เลขฐานสิบหก (ใช้ตัวพิมพ์ใหญ่ A–F ไม่มี 0 นำหน้า ยกเว้นเลข 0)
แต่รายการสีที่รุ่นพี่ส่งมาเป็นเลขฐานสิบยาวเหยียด เชนเลยต้องแปลงทั้งหมดก่อนเริ่มงาน
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- จำนวนเต็ม `n` ตัวเดียว (0 <= n <= 10^15)

## Output
- บรรทัดเดียว: เลขฐานสิบหก

## ตัวอย่าง
```
input:
1029301932312

output:
EFA72D1118
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
