# ค้นตำแหน่งแรก (Lower Bound)

ห้องสมุดโรงเรียนเก็บหนังสือเป็นชั้นยาวเหยียด เรียงตามรหัสหนังสือจากน้อยไปมากแล้ว (`a[1] <= a[2] <= ... <= a[N]`) ฟ้าเป็นบรรณารักษ์ต้องตอบคำถามจากนักเรียนวันละหลายแสนครั้งว่า "หนังสือรหัสอย่างน้อย `X` เล่มแรกสุดอยู่ช่องที่เท่าไร" ถ้าหาไม่เจอเลยให้ตอบ `-1`

ถ้าไล่ดูทีละช่องทุกครั้งคงตอบไม่ทันก่อนห้องสมุดปิด จงเขียนโปรแกรมที่ตอบคำถามทั้งหมดให้เร็วที่สุด

## Input

- บรรทัดแรก: `N Q` (1 <= N, Q <= 200000) จำนวนหนังสือและจำนวนคำถาม
- บรรทัดที่สอง: รหัสหนังสือ `N` ตัว เรียงจากน้อยไปมาก (`|a[i]| <= 10^9`)
- อีก `Q` บรรทัด: คำถามละหนึ่งบรรทัด เป็นจำนวนเต็ม `X` (`|X| <= 10^9`)

## Output

- `Q` บรรทัด บรรทัดที่ `i` คือหมายเลขช่อง (เริ่มนับจาก 1) ของหนังสือเล่มแรกที่มีรหัสมากกว่าหรือเท่ากับ `X` ถ้าไม่มีเลยตอบ `-1`

## ตัวอย่าง

```
input:
5 4
2 4 4 7 10
4
1
11
7

output:
2
1
-1
4
```

```
input:
1 3
5
5
4
6

output:
1
1
-1
```

## Limits

- เวลา 1 วินาที, หน่วยความจำ 256 MB
