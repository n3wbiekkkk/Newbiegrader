# ยอดขายสายไหมรายวัน (Daily Candy Sales)

จดยอดขาย `N` วัน มีคำถาม `Q` ข้อ แต่ละข้อถามผลรวมยอดขายตั้งแต่วันที่ `l` ถึง `r`

## Input
- บรรทัดแรก: `N Q` (1 <= N, Q <= 200000)
- บรรทัดที่สอง: ยอดขายวันที่ 1 ถึง N (0 <= แต่ละวัน <= 10^9)
- อีก Q บรรทัด: `l r` (1 <= l <= r <= N)

## Output
- Q บรรทัด: ผลรวมของแต่ละคำถาม

## ตัวอย่าง
```
input:
6 3
3 1 4 1 5 9
1 3
2 5
4 6

output:
8
11
15
```

## Subtask
- กลุ่ม 1 (40 คะแนน): N, Q <= 1000
- กลุ่ม 2 (60 คะแนน): ไม่มีเงื่อนไขเพิ่มเติม

## Limits
- เวลา 1 วินาที, หน่วยความจำ 256 MB
- ผลรวมอาจเกิน 32-bit (แนะนำ 64-bit)
