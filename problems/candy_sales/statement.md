# ยอดขายสายไหมรายวัน (Daily Candy Sales)

ข้าวปุ้นกับข้าวปั้นเปิดร้านขายสายไหมที่ตลาดนัดทุกวัน
ข้าวปุ้นจดยอดขายของแต่ละวันไว้ในสมุด เป็นเวลา `N` วันติดต่อกัน

วันหนึ่ง ปุนซึ่งเป็นเจ้าของตลาดมาขอสอบถามยอดรวม
เขาถามหลายครั้งว่า "ตั้งแต่วันที่ `l` ถึงวันที่ `r` ขายได้รวมกี่ถุง"
ถ้าข้าวปุ้นต้องบวกใหม่ทุกครั้งคงไม่ไหว เพราะมีคนถามเยอะมาก จงช่วยตอบทุกคำถามให้เร็วที่สุด

## Input
- บรรทัดแรก: `N` และ `Q` (1 <= N, Q <= 200000)
- บรรทัดที่สอง: ยอดขายวันที่ 1 ถึง `N` (0 <= ยอดขายแต่ละวัน <= 10^9)
- อีก `Q` บรรทัด: `l` และ `r` (1 <= l <= r <= N)

## Output
- `Q` บรรทัด แต่ละบรรทัดคือยอดรวมที่ถูกถาม

## ตัวอย่าง
```
input:
6 3
3 1 4 1 5 9
1 3
2 5
4 6

output:
8
11
15
```
วัน 1–3 = 3+1+4 = 8, วัน 2–5 = 1+4+1+5 = 11, วัน 4–6 = 1+5+9 = 15

## Subtask
- กลุ่ม 1 (40 คะแนน): N, Q <= 1000
- กลุ่ม 2 (60 คะแนน): ไม่มีเงื่อนไขเพิ่มเติม

## Limits
- เวลา 1 วินาที, หน่วยความจำ 256 MB
- ผลรวมอาจเกิน 32-bit (แนะนำ 64-bit)
