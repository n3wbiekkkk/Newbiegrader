# ตรวจจำนวนเฉพาะ (Prime Check)

ฟ้าอยากรู้ว่าเลขที่สุ่มได้เป็นจำนวนเฉพาะหรือไม่ (มากกว่า 1 และหารลงตัวแค่ 1 กับตัวเอง)
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่งเขียนฟังก์ชัน — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- จำนวนเต็ม `n` ตัวเดียว (1 <= n <= 10^9)

## Output
- `YES` ถ้าเป็นจำนวนเฉพาะ ไม่งั้น `NO`

## ตัวอย่าง
```
input:
999999937

output:
YES
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
