# ตรวจจำนวนเฉพาะ (Prime Check)

พักกลางวันในค่าย ฟ้ากับเพื่อนเล่นเกมทายใจกัน กติกาคือใครสุ่มจับฉลากได้ "จำนวนเฉพาะ"
จะได้ขนมฟรีหนึ่งห่อ (จำนวนเฉพาะคือเลขมากกว่า 1 ที่หารลงตัวแค่ 1 กับตัวเอง)
ฟ้าอยากรู้ก่อนตะโกนตอบว่าเลขในมือใช่จำนวนเฉพาะหรือไม่ จะได้ไม่หน้าแตก
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่งเขียนฟังก์ชัน — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- จำนวนเต็ม `n` ตัวเดียว (1 <= n <= 10^9)

## Output
- `YES` ถ้าเป็นจำนวนเฉพาะ ไม่งั้น `NO`

## ตัวอย่าง
```
input:
999999937

output:
YES
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
