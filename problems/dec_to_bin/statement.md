# แปลงเลขฐานสิบเป็นฐานสอง (Decimal to Binary)

น้ำส่งรหัสลับเป็นเลขฐานสิบ `n` ชุด ต้องแปลงแต่ละตัวเป็นเลขฐานสอง (ไม่มี 0 นำหน้า ยกเว้นเลข 0)
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- บรรทัดแรก: จำนวนชุด `n` (1 <= n <= 20)
- บรรทัดที่สอง: จำนวนเต็ม `n` ตัว (0 <= ค่า <= 10^9)

## Output
- `n` บรรทัด: เลขฐานสองของแต่ละจำนวน

## ตัวอย่าง
```
input:
3
6 15 19

output:
110
1111
10011
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
