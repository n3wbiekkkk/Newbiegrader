# ผลรวมลำดับฟีโบนัชชี (Fibonacci Sum)

โตโน่เริ่มเลี้ยงกระต่ายตามตำนานที่ครูเล่าให้ฟัง แม่พันธุ์ออกลูกเป็นลำดับฟีโบนัชชีทุกเดือน
(`F(0) = 0, F(1) = 1` ตัวต่อๆ ไปเท่ากับผลบวกของสองเดือนก่อนหน้า)
สิ้นปีโตโน่อยากรู้ว่าตั้งแต่เดือนที่ 0 ถึงเดือนที่ `n` มีกระต่ายเกิดรวมทั้งหมดกี่ตัว
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- จำนวนเต็ม `n` (0 <= n <= 30)

## Output
- บรรทัดเดียว: ผลรวม

## ตัวอย่าง
```
input:
7

output:
33
```

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
