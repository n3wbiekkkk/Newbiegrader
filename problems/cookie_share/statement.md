# แบ่งคุกกี้ ห.ร.ม. ค.ร.น. (Cookie Sharing)

ร้านขนมของแม่นัทขายคุกกี้ช็อกโกแลตกล่องละ `A` ชิ้น ส่วนร้านแม่เมย์ขายคุกกี้เนยกล่องละ `B` ชิ้น
สองบ้านจะจัดปาร์ตี้ร่วมกัน นัทกับเมย์เลยเอาคุกกี้บ้านละ 1 กล่องมากองรวม
คำถามที่ 1: ถ้าจะแจกเพื่อนให้ทุกคนได้สองรสเท่ากันไม่เหลือเศษ จะแจกได้มากสุดกี่คน
คำถามที่ 2: ถ้าจะซื้อเพิ่มทีละกล่องจนสองรสมีจำนวนเท่ากันพอดี (ซื้อน้อยสุด) ต้องเพิ่มรสละกี่ชิ้น
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- `A B` (1 <= A, B <= 10^9)

## Output
- บรรทัดเดียว: `เพื่อนมากสุด ช็อกโกแลตที่เพิ่ม เนยที่เพิ่ม`

## ตัวอย่าง
```
input:
1000000000 999999999

output:
1 999999998000000000 999999998000000001
```
(ระวังล้น 32-bit แนะนำ 64-bit และหารก่อนคูณตอนหา ค.ร.น.)

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
