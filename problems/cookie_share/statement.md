# แบ่งคุกกี้ ห.ร.ม. ค.ร.น. (Cookie Sharing)

นัทมีคุกกี้ช็อกโกแลต 1 กล่อง (`A` ชิ้น) เมย์มีคุกกี้เนย 1 กล่อง (`B` ชิ้น)
คำถามที่ 1: แจกเพื่อนให้ทุกคนได้เท่ากันไม่เหลือเศษ ได้มากสุดกี่คน (ห.ร.ม.)
คำถามที่ 2: ซื้อเพิ่มทีละกล่องจนสองชนิดเท่ากันพอดี (ซื้อน้อยสุด) ต้องเพิ่มชนิดละกี่ชิ้น
ข้อนี้ใช้ภาษา/วิธีใดก็ได้ (ต้นฉบับ PDF สั่ง recursion — ไม่บังคับแล้ว)
ส่งโปรแกรมเต็มที่อ่าน input ตาม spec นี้

## Input
- `A B` (1 <= A, B <= 10^9)

## Output
- บรรทัดเดียว: `เพื่อนมากสุด ช็อกโกแลตที่เพิ่ม เนยที่เพิ่ม`

## ตัวอย่าง
```
input:
1000000000 999999999

output:
1 999999998000000000 999999998000000001
```
(ระวังล้น 32-bit แนะนำ 64-bit และหารก่อนคูณตอนหา ค.ร.น.)

## Limits
- เวลา 1 วินาที, หน่วยความจำ 64 MB
