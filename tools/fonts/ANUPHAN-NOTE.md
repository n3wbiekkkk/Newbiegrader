# Anuphan for the PDF wordmark

Source: https://github.com/google/fonts/tree/95f4904fc8bcf26d3420fe315560c96417c6dec7/ofl/anuphan

The bundled Regular (400) and SemiBold (600) files are static instances of
`Anuphan[wght].ttf`, generated with fontTools 4.61.1
(`instantiateVariableFont(..., {"wght": weight}, updateFontNames=True)`).
Upstream variable-font SHA-256: `7ec47ebcaa9d6459d974691cbb42fae52e1449478a607b071bfaf3ccdb433ce4`.
See `OFL-anuphan.txt` for the upstream license. These files let tectonic build
the same web wordmark offline; the statement body keeps its existing fonts.
