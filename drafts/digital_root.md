# รหัสลับเลขซ้ำ (digital_root)

ครูให้รหัสลับมาเป็นจำนวนเต็มบวก `X` วิธีถอดรหัสคือ บวกเลขโดดทุกหลักเข้าด้วยกัน
ทำซ้ำจนเหลือเลขหลักเดียว เลขนั้นคือรหัสที่แท้จริง ส่วนจำนวนรอบที่ทำคือ
"ระดับความลับ" ของรหัส

เช่น `X = 987` รอบที่ 1 ได้ `9+7+8 = 24` รอบที่ 2 ได้ `2+4 = 6`
รหัสที่แท้จริงคือ `6` ระดับความลับคือ `2`

## Input
- บรรทัดเดียว: `X` (`1 <= X <= 10^100000` คือยาวได้ถึงหนึ่งแสนหลัก)

## Output
- บรรทัดที่ 1: รหัสที่แท้จริง (เลขหลักเดียว)
- บรรทัดที่ 2: ระดับความลับ (จำนวนรอบ) ถ้า `X` หลักเดียวอยู่แล้วตอบ `0`

## ตัวอย่าง
```
input:
987

output:
6
2
```

```
input:
5

output:
5
0
```

## Constraints
- `X` ยาวได้ถึง `100000` หลัก (ห้ามแปลงเป็น int ตรงๆ)

## Subtasks
- 30 คะแนน: `X <= 10^18`
- 70 คะแนน: เต็ม
