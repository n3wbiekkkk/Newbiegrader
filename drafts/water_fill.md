# ถังน้ำล้น (water_fill)

มีถังน้ำ `M` ใบเรียงกัน ถังใบที่ `i` จุได้ `c[i]` ลิตร ตอนแรกทุกใบว่าง
มีคนมาเทน้ำ `Q` ครั้ง ครั้งที่ `j` เทน้ำ `x[j]` ลิตรลงถังใบที่ `p[j]`
ถ้าน้ำเกินความจุ ส่วนที่ล้นจะไหลไปถังใบถัดไป (`i+1`) ทันที
(ถังใบสุดท้ายล้นแล้วน้ำส่วนเกินหกลงพื้นหายไป) น้ำที่อยู่ในถังไม่หายไปไหน

หลังเทครบทุกครั้ง จงบอกปริมาณน้ำในถังแต่ละใบ

## Input
- บรรทัดที่ 1: `M Q` (`1 <= M, Q <= 100000`)
- บรรทัดที่ 2: `c[1]..c[M]` (`1 <= c[i] <= 10^9`)
- อีก `Q` บรรทัด: `p[j] x[j]` (`1 <= p[j] <= M`, `1 <= x[j] <= 10^9`)

## Output
- บรรทัดเดียว: ปริมาณน้ำในถังที่ `1..M` คั่นด้วยช่องว่าง

## ตัวอย่าง
```
input:
3 2
5 5 5
1 7
2 4

output:
5 5 1
```
อธิบาย: เท 7 ลงถัง 1 (จุ 5) ล้น 2 ไปถัง 2 → ถัง 1=5 ถัง 2=2
แล้วเท 4 ลงถัง 2 → ถัง 2=6 เกินจุ 5 ล้น 1 ไปถัง 3 → 5 5 1

```
input:
2 1
10 10
2 3

output:
0 3
```

## Constraints
- `M, Q` สูงสุด `100000` วิธีจำลองทีละลิตรจะช้าเกิน ต้องคิดแบบทีละถัง

## Subtasks
- 30 คะแนน: `M, Q <= 1000`
- 70 คะแนน: เต็ม
