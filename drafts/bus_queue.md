# ต่อแถวขึ้นรถ (bus_queue)

มีคน `N` คนยืนต่อแถวขึ้นรถเมล์ รถเมล์มาทุก `T` นาที เริ่มคันแรกเวลา `0`
(คันที่ 1, 2, 3, ... มาตอนเวลา `0, T, 2T, ...`) รถแต่ละคันรับได้ไม่เกิน `K` คน
คนที่มาก่อนได้ขึ้นก่อน ถ้าคันไหนเต็ม คนที่เหลือรอคันถัดไป

คนทั้ง `N` คนมาถึงป้ายพร้อมกันตั้งแต่เวลา `0` จงหาว่าคนสุดท้ายได้ขึ้นรถเวลาเท่าไร

## Input
- บรรทัดเดียว: `N K T` (`1 <= N <= 100000`, `1 <= K <= 1000`, `1 <= T <= 1000`)

## Output
- เวลาที่คนสุดท้ายได้ขึ้นรถ (นาที)

## ตัวอย่าง
```
input:
5 2 10

output:
20
```
อธิบาย: คันเวลา 0 รับ 2 คน, คันเวลา 10 รับ 2 คน, คันเวลา 20 รับ 1 คนสุดท้าย

```
input:
4 4 7

output:
0
```

## Constraints
- `N` สูงสุด `100000`

## Subtasks
- 30 คะแนน: `N <= 100`
- 70 คะแนน: เต็ม
