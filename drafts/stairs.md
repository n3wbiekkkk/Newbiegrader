# ขึ้นบันได (stairs)

บันไดมี `N` ขั้น จะก้าวทีละ `1` ขั้นหรือทีละ `2` ขั้นก็ได้
จงหาว่ามีวิธีก้าวขึ้นไปยืนบนขั้นที่ `N` ได้ทั้งหมดกี่วิธี
(เริ่มจากพื้นก่อนขั้นที่ 1) ตอบเป็นเศษจากการหารด้วย `1000000007`

เช่น `N = 3` มี `3` วิธี: `1+1+1`, `1+2`, `2+1`

## Input
- บรรทัดเดียว: `N` (`1 <= N <= 1000000`)

## Output
- จำนวนวิธี mod `1000000007`

## ตัวอย่าง
```
input:
3

output:
3
```

```
input:
5

output:
8
```

## Constraints
- `N` สูงสุด `1000000` ต้องตอบใน `1` วินาที (วิธี recursive ตรงๆ จะช้าเกิน)

## Subtasks
- 30 คะแนน: `N <= 20`
- 70 คะแนน: เต็ม
