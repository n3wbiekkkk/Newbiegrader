# คำสลับอักษร (anagram)

เพื่อนส่งกระดาษมาสองบรรทัด อ้างว่าเป็นคำเดียวกันแต่สลับอักษรกัน
(anagram) เช่น `listen` กับ `silent` ให้ตอบ `YES` ถ้าใช่ ไม่งั้นตอบ `NO`

การเปรียบเทียบแยกพิมพ์เล็กพิมพ์ใหญ่ (`A` กับ `a` ถือเป็นคนละตัว)
และนับช่องว่างกับเครื่องหมายทุกตัวด้วย

## Input
- บรรทัดที่ 1: สายอักขระ `A` (ยาว `1..100000` ตัวอักษรภาษาอังกฤษ ช่องว่าง และเครื่องหมาย)
- บรรทัดที่ 2: สายอักขระ `B` (เงื่อนไขเดียวกัน)

## Output
- `YES` ถ้า `B` สลับอักษรจาก `A` ได้ ไม่งั้น `NO`

## ตัวอย่าง
```
input:
listen
silent

output:
YES
```

```
input:
hello
world

output:
NO
```

## Constraints
- ความยาวรวมสูงสุด `200000` ต้องตอบใน `1` วินาที (ห้าม sort แล้วรอดทุกเคสที่ time limit โหด — ควรนับความถี่)

## Subtasks
- 40 คะแนน: ยาวไม่เกิน `1000`
- 60 คะแนน: เต็ม
